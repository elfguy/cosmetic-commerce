# Aqua Lotion V4 생성 계획

## 방향

- **베이스:** V2 전체 톤/가독성/대표이미지 유지
- **보강:** V3의 좋은 첫 페이지, EWG 그린/약산성 pH, 사용법 사진 흐름, 친환경 포장, 제조사 직접판매 요소 통합
- **생성 방식:** ChatGPT 웹 GPT Images Pro 모드에서 새 세션으로 생성
- **생성 단위:** 한 번에 전체 생성 금지. 참조 이미지 한계와 품질 저하 방지를 위해 1~2컷씩 분리 생성
- **상세 컷 크기:** V2 02와 비슷한 긴 모바일 상세 이미지 비율로 통일. 목표 약 `941 × 1672` 또는 동일 비율
- **대표 이미지:** V2 대표이미지 그대로 사용

## 제품 표현 필수 조건

1. 제품 내용물은 **흰색**이어야 함.
2. 용기 전체가 흰색 통처럼 보이면 안 됨.
3. 원본 제품사진처럼 **용기 맨 윗부분은 투명하게 비어 보이는 느낌**이 살아야 함.
4. 펌프/라벨/브랜드는 실제품 기준으로 유지.
5. STOP/잠금 방향 설명 금지. 펌프가 풀리는 잘못된 사용법으로 보이면 안 됨.
6. 이미지 안에 `CUT`, `DETAIL CUT`, `POINT 01`, `STEP 01`, 독립 숫자 배지 같은 컷 번호성 표기 금지.
7. 한국어 텍스트는 크게, 핵심 문구 위주. 작은 설명문은 최소화.

## V4 상세 컷 구성

### 01. 히어로
- V3 01의 첫 페이지 느낌을 베이스로 함.
- V2 01보다 더 프리미엄하고 시원한 첫 인상.
- 제품은 원본 제품사진처럼 상단 투명감 + 흰색 내용물.
- 핵심 문구: `히알루론산 아쿠아 로션`, `수분 · 진정 · 보호를 한 번에`, `제조 6개월 이내 신선 제품 보장`.

### 02. 가족 데일리 보습
- V2 02의 가족/데일리 보습 페이지 유지.
- 길이/톤 기준 컷.
- 자극적이지 않고 온 가족이 쓰는 산뜻한 보습 이미지.

### 03. 제품 필요 상황 / 크림 부담 대안
- V2 대표이미지/상세 흐름의 장점 반영.
- `크림은 무겁고 토너는 부족할 때` 같은 문제-해결 구조.
- 제품은 정확한 흰색 내용물 + 투명한 상단.

### 04. 핵심 수분·진정 성분
- V2의 8종 히알루론산, 병풀추출물, 해양심층수, Fresh Bud No.6 흐름.
- 원료 이미지는 과장 없이 깨끗하게.

### 05. 특허 진정 원료 통합
- V2 05와 V2 06을 **한 페이지로 통합**.
- 전체적인 느낌은 V2 06이 더 좋으므로 V2 06 레이아웃/톤을 우선.
- 특허성분 이미지를 원료 접시/식물 이미지로 표현.
- 특허/시험성적서 느낌은 공식 인증처럼 과장하지 않기.

### 06. 발효성분 보강
- V2 07을 개선.
- 가운데가 비지 않게 발효성분 원본 이미지/원료 이미지를 배치.
- 반드시 성분명 표기:
  - `효모/겨우살이추출물`
  - `효모/띠뿌리발효추출물`
  - `락토바실러스/콩발효추출물`
- 기존 V2 07의 발효성분 & 식물 오일 블렌딩 흐름을 유지하되 더 풍성하게.

### 07. EWG 그린 & 약산성 pH
- V2에는 없던 V3 06, V3 07 내용을 통합.
- `전성분 EWG 그린 등급`, `약산성 pH 5.0~6.5`, `피부 밸런스 케어`를 넣음.
- EWG VERIFIED 같은 공식 인증으로 오인되는 마크 금지. 일반 설명형 그래픽만 사용.

### 08. 제조일자/신선 제품 보장
- V2 09의 중간 이하 어려운 설명은 제거.
- V3 07 하단처럼 그림식 비교로 쉽게 설명.
- `제조일자 확인`, `제조 6개월 이내 신선 제품`, `사용기한만 보는 제품과의 차이`를 소비자가 이해하기 쉽게.

### 09. 사용법 + 친환경 포장 + 제조사 직접판매
- V3 08의 사용법 사진 흐름 참고.
- STOP/잠금 설명 금지.
- `얼굴/몸에 부드럽게 펴 바르기`, `건조한 부위에 덧바르기` 정도로 간단하게.
- V3 08의 친환경 포장, 제조사가 직접판매 내용을 함께 추가.

### 10. 마무리 신뢰/제품 정보
- V2 10~11 또는 V3의 제품 정보 흐름 참고.
- 제품명, 용량, 제조/판매 정보는 깔끔하게.
- 구매 전환용 마무리. 과장 claims 금지.

## 생성 순서

1. 참조 보드 + 원본 대표 01 + V2 대표 01 + V3 detail 01을 첨부해 **01 히어로 proof cut** 먼저 생성.
2. 01 품질 확인 후 02~04 생성.
3. 05~06은 특허/발효 원료 참조 이미지를 추가해서 별도 생성.
4. 07~08은 V3 06/07 참조를 추가해서 별도 생성.
5. 09~10은 V3 08, V2 09~11 참조를 추가해서 별도 생성.
6. 전체 다운로드 후 contact sheet 생성.
7. 개별 컷 검수: 제품 내용물 색, 용기 투명 상단, 한국어 오탈자, 컷 번호성 텍스트, STOP 문구, EWG 공식인증 오인 여부.
8. `manifest.json`에 새 V4 등록 후 빌드 검증.
