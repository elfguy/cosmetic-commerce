좋아. 방금 생성한 V4 상세 01번 메인 히어로 방향은 통과입니다.
이제 같은 품질/무드로 V4 상세페이지 나머지 컷을 생성해줘.

중요:
- 반드시 GPT Images / ChatGPT image generation으로 실제 이미지 파일을 만들어줘.
- 텍스트 설명만 하지 말고, 각 컷별 이미지를 생성해줘.
- Hermes/외부 로컬 이미지 생성이 아니라, 여기 ChatGPT 웹에서 생성해야 합니다.
- 이번 요청은 상세 02~10 총 9장입니다.
- 각 이미지는 쿠팡 모바일 상세페이지용 세로형, 01번과 같은 폭/스타일/톤으로 통일.
- 가능하면 각 컷을 별도 이미지로 생성해줘.
- 한국어 텍스트는 크고 읽기 쉽게, 작은 글자는 최소화.
- 제품 라벨/로고는 가능한 한 원본 제품 느낌을 유지하되, 왜곡된 글자나 가짜 브랜드 로고가 과하게 생기지 않게.
- 화장품 법규상 치료/완치/아토피/여드름 치료/절대 효과 표현 금지.

전체 공통 디자인:
- 깨끗한 화이트 + 아쿠아 블루 + 포인트 그린.
- 프리미엄/클린/수분감/고급 화장품 광고 느낌.
- V2의 정돈된 정보 구성과 V3의 시각적 임팩트를 참고하되 그대로 복사하지 말 것.
- 제품 용기는 흰색 로션 내용물이 들어 있고, 상단/어깨/넥 부분은 투명 용기 느낌이 보이게.

생성할 컷:

02. 이런 분께 추천
- V2의 깔끔한 추천/체크리스트 느낌.
- 카피 예시:
  이런 분께 추천합니다
  속건조가 느껴지는 피부
  끈적임 없는 산뜻한 보습을 원하는 분
  피부 진정과 데일리 보습을 함께 원하는 분
  얼굴과 바디 모두 편하게 쓰고 싶은 분
- 체크리스트/피부 수분 아이콘 중심, 너무 복잡하지 않게.

03. 8중 히알루론산 전문 페이지
- 물방울/분자/피부 레이어 단면/8HA 구조.
- 카피:
  8종 히알루론산 레이어 보습
  피부 겉부터 속까지 겹겹이 수분을 채웁니다
  겉 수분 보호 → 속수분 충전 → 깊은 수분 전달
- 하단 작은 주의 문구: *상기 내용은 원료적 특성에 한함
- 전문적이지만 너무 의료 느낌은 피하기.

04. 자연 유래 진정과 영양 케어
- 병풀추출물, 해양심층수, AHA·PHA, Fresh Bud No.6, 시어오일 블렌딩, 발효추출물 카드.
- 카피:
  자연 유래 성분으로 편안한 데일리 케어
  수분 · 진정 · 피부결 · 영양 보습
- 성분 카드형 레이아웃.

05. Fresh Bud No.6 원료 특성
- 기존 특허번호/임의 번호/시험번호 절대 넣지 말 것.
- 카피:
  Fresh Bud No.6
  새싹 유래 원료 특성 기반 케어
  피부를 편안하게 감싸는 그린 보습 포뮬러
- 특허/인증마크처럼 보이는 공식 배지는 만들지 말고, 병풀잎/새싹/그린 포인트 중심.
- 하단 작은 주의 문구: *상기 내용은 원료적 특성에 한함

06. EWG 그린, 무향, 저자극 테스트
- EWG VERIFIED 인증마크처럼 보이는 로고/공식 도장 금지.
- 임의 시험번호/기관명/수치 금지.
- 카피:
  전성분 EWG 그린 등급 기준으로 설계
  무향 타입
  피부 저자극 테스트 완료
- 신뢰감 있는 카드/아이콘 느낌. 단, 공식 인증서처럼 과장하지 말 것.

07. 약산성 pH + 발효성분
- 카피:
  피부 밸런스를 지키는 약산성 pH
  pH 5.0~pH 6.5 데일리 밸런스 케어
  발효 유래 성분으로 편안한 보습 케어
- 성분명:
  효모/겨우살이추출물
  효모/띠뿌리발효추출물
  락토바실러스/콩발효추출물
- pH 곡선/발효성분 일러스트/자연 이미지.

08. 제조일자의 신선함
- 카피:
  신선함은 제조일자에서 시작됩니다
  제조 6개월 이내 제품만 출고
  제조번호와 제조일자로 언제 만들었는지 바로 확인
- 사용기한만 강조하는 느낌보다 제조일자/신선 출고 메시지를 직관적 카드/라벨로.
- 임의 제조번호는 흐릿한 예시 정도만. 실제처럼 오해되는 구체 번호 과다 노출 금지.

09. 사용법
- STOP 방향/잠금/해제 회전 안내 절대 넣지 말 것.
- 펌프를 손으로 눌러 적당량 덜어 쓰는 직관적 이미지.
- 카피:
  How to use
  샤워 후 또는 건조함이 느껴질 때 적당량을 덜어 부드럽게 펴 발라주세요.
  얼굴 · 바디 모두 데일리 보습으로 사용 가능합니다.

10. 실속 포장과 제조사 직접 판매
- 수축필름 제거 표현 금지. “수축필름”이라는 단어도 넣지 말 것.
- 카피:
  불필요한 단상자를 없애고 실속 있게 포장합니다
  제조사가 직접 만들어 직접 판매합니다
  합리적인 가격과 신선한 유통 구조
- 친환경/직접판매/합리적 가격/박스 이미지. 단, 과장된 친환경 인증마크 금지.

- 가능하면 한 번에 9장 생성. 어렵다면 순서대로 여러 장 생성해도 됨.
