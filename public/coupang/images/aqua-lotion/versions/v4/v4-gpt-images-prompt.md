# ChatGPT Images 2.0 Prompt — YOURSKIN+ Hyaluronic Acid Aqua Lotion V4

업로드한 레퍼런스 이미지를 모두 참고해서, 쿠팡 모바일 상세페이지용 `아쿠아로션 V4`를 제작해줘.

## 전체 방향
- V2의 전체적인 프리미엄/클린/아쿠아 무드와 정보 구성을 기본으로 유지.
- 첫 페이지의 임팩트는 V3의 01이 더 좋아 보이므로 V3 01의 물결감, 중앙 제품 강조, 원형 성분 배지 구성을 반영.
- 결과물은 한국 쿠팡 상세페이지 스타일, 모바일 가독성 중심, 깨끗한 화이트 + 아쿠아 블루 + 포인트 그린.
- 페이지별 세로 길이는 너무 짧지 않게, 각 컷을 약 `780 × 1500~1600px` 정도 느낌으로 통일. 너무 압축하지 말고 소비자가 충분히 읽을 수 있는 상세페이지 길이로 구성.
- V4는 대표이미지는 V2 대표이미지를 유지하는 방향. 지금 요청은 상세페이지 V4 컷 제작.

## 매우 중요한 제품 표현 수정
- 제품 용기 내용물은 반드시 `흰색 로션`으로 표현.
- 단, 병 전체가 흰 플라스틱처럼 보이면 안 됨.
- 원본 제품 사진처럼 용기 맨 윗부분/어깨/넥 부분은 투명한 용기 느낌이 보여야 함.
- 내용물이 병 전체 끝까지 가득 찬 것처럼 만들지 말고, 상단 투명 용기 공간이 보이게 표현.
- 라벨/브랜드/제품명은 가능한 한 원본 제품 사진을 기준으로 깔끔하게 유지. 왜곡된 글자나 가짜 로고를 만들지 말 것.

## 상세페이지 컷 구성 제안 — V4

### 01. 메인 히어로
- V3 01의 전체 느낌을 기본으로 사용.
- 중앙에 실제 아쿠아로션 제품, 주변에 물보라/수분감/원형 성분 배지.
- 카피:
  - `히알루론산 아쿠아 로션`
  - `끈적임 없이 산뜻하게`
  - `수분 · 진정 · 보호를 한번에!`
  - `제조 6개월 이내 신선 제품 보장`
- 성분/특징 배지: `8중 히알루론산`, `병풀추출물`, `해양심층수`, `AHA·PHA`, `Fresh Bud No.6`, `발효추출물·식물오일 블렌딩`.
- 제품 내용물 흰색 + 상단 투명 용기 표현 필수.

### 02. 이런 분께 추천
- V2의 깔끔한 추천/체크리스트 느낌 유지.
- 속건조, 산뜻한 보습, 피부 진정, 매끈한 피부결, 온 가족 데일리 보습 사용감을 짧은 문장으로.

### 03. 8중 히알루론산 전문 페이지
- V1 03의 전문적이고 과학적인 느낌을 강하게 반영.
- 물방울/분자/피부 레이어 단면/8HA 구조를 사용.
- 카피:
  - `8종 히알루론산 레이어 보습`
  - `피부 겉부터 속까지 겹겹이 수분을 채웁니다`
- 단계: `겉 수분 보호 → 속수분 충전 → 깊은 수분 전달`
- 8종 리스트는 보기 좋게: 고분자, 중분자, 중·저분자, 저분자, 초저분자, 하이드롤라이즈드, 아세틸, 소듐하이알루로네이트.
- 하단 주의 문구 작게: `*상기 내용은 원료적 특성에 한함`.

### 04. 자연 유래 진정 & 영양 케어
- V2 기반 + V3의 정돈된 성분 카드 느낌.
- 병풀추출물, 해양심층수, AHA·PHA, Fresh Bud No.6, 시어오일 블렌딩, 발효추출물을 카드형으로 배치.
- 피부 진정/수분/매끄러운 피부결/영양 보습을 과장 없이 표현.

### 05. 특허성분 Fresh Bud No.6
- 기존 V3 05/06처럼 나뉘어 보이는 특허성분 설명은 한 페이지로 통합.
- 전체 느낌은 V3 06이 더 나으므로, V3 06의 신뢰감 있는 인증/시험성적서 느낌을 참고.
- `Fresh Bud No.6`를 핵심 특허성분으로 강조.
- 병풀잎/새싹/그린 포인트 + 특허/신뢰 배지 느낌.
- 너무 복잡하지 않게 한 컷 안에서 “특허성분 + 저자극/신뢰”를 정리.

### 06. EWG 그린 & 무향 & 저자극 테스트
- V3 06의 내용을 V2에 추가하는 개념.
- 카피:
  - `전성분 100% EWG 그린 등급`
  - `무향(또는 미향)`
  - `피부 저자극 테스트 완료`
- 시험성적서/인증 카드/그린 등급 아이콘을 고급스럽게 표현.
- 의료/치료 느낌 없이 화장품 안전성 신뢰 톤으로.

### 07. 약산성 pH + 발효성분 설명
- V3 07의 약산성 pH 내용을 반영하되, 가운데가 비어 보이지 않게 보완.
- 발효성분이 무엇인지 명확히 보여줄 것.
- 포함 성분명:
  - `효모/겨우살이추출물`
  - `효모/띠뿌리발효추출물`
  - `락토바실러스/콩발효추출물`
- 원본/자연 이미지 느낌의 작은 성분 비주얼을 넣어 중앙 빈 공간을 채우기.
- 카피:
  - `피부 밸런스를 지키는 약산성 pH`
  - `pH 5.0~pH 6.5 데일리 밸런스 케어`
  - `발효 유래 성분으로 편안한 보습 케어`

### 08. 제조일자의 신선함
- V2 09의 상단 신선함 메시지는 유지하되, 중간 이하 설명은 소비자가 어렵게 느낄 수 있으니 V3 07 하단처럼 그림/예시 중심으로 수정.
- V1 06 하단부의 깔끔한 제조일자/신선함 표현을 참고.
- 카피:
  - `신선함은 제조일자에서 시작됩니다`
  - `제조 6개월 이내 제품만 출고`
  - `제조번호와 제조일자로 언제 만들었는지 바로 확인`
- 사용기한만 강조하는 제품과 비교하되, 너무 복잡한 표는 피하고 직관적인 카드/스티커/라벨 예시로.

### 09. 사용법
- V3 10의 STOP 내용은 잘못됨. STOP 방향으로 돌리면 펌프 자체가 풀릴 수 있으므로 그 방식으로 안내하지 말 것.
- V3 08의 사진/그림이 더 나으므로 펌프를 손으로 눌러 적당량을 덜어 쓰는 직관적 이미지 사용.
- 카피:
  - `How to use`
  - `샤워 후 또는 건조함이 느껴질 때 적당량을 덜어 부드럽게 펴 발라주세요.`
  - `얼굴·바디 모두 데일리 보습으로 사용 가능합니다.`
- 잘못된 STOP/잠금/해제 회전 안내는 넣지 말 것.

### 10. 친환경 포장 & 제조사 직접 판매
- V3 08의 친환경 포장/제조사 직접 판매 내용을 V2에 추가.
- 특히 V1 08 하단부가 더 좋아 보이므로 그 구조와 카피 톤을 참고.
- 수정 문구 필수:
  - `불필요한 단상자를 없애고 실속 있게 포장합니다`
  - `제조사가 직접 만들어 직접 판매합니다`
- `불필요한 단상자와 수축필름은 없애고`라는 문구는 쓰지 말 것. 수축필름은 앞으로 사용할 예정이므로 `수축필름` 제거 표현 금지.
- 친환경/직접판매/합리적 가격/신선한 유통 구조를 아이콘과 박스 이미지로 표현.

### 11. 무단 리셀러/정품 구매 주의
- V3 09의 경고 페이지를 너무 무겁지 않게, 신뢰감 있는 안내 페이지로 마무리.
- `YOURSKIN+ 공식 판매처에서 구매해 주세요` 중심.

## 제작 시 주의
- 한국어 텍스트는 깨지지 않게, 실제 상세페이지에 쓰일 수 있게 깔끔한 고딕체로.
- 너무 많은 작은 글자를 AI로 억지 생성하지 말고, 큰 제목/핵심 문구 중심으로 구성.
- 화장품 법규상 과장 표현 금지: 치료, 완치, 아토피 개선, 여드름 치료 같은 표현 금지.
- 전체 디자인은 고급 화장품 광고 느낌 + 쿠팡 모바일 상세페이지 가독성을 동시에 만족.
- 물, 투명감, 화이트 로션, 그린 성분 이미지를 조화롭게 사용.
