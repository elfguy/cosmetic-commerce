목표: 유어스킨플러스 로즈 다마스쿠스 토닉 에센스 상세페이지 V1의 7번째 컷.

[컷의 역할]
사람이 실제로 토닉 에센스를 사용하는 장면을 보여주는 라이프스타일 사용 컷입니다.
사용자는 "사람이 사용하는 컷도 하나 있으면 좋겠다"고 했으므로, 이 컷은 정보 카드보다 실제 사용 이미지가 중심입니다.
얼굴은 절대 넣지 말고, 깨끗한 손/화장솜/손등/세면대 위 제품 분위기로 자연스럽게 표현하세요.
제품병은 보이더라도 라벨이 심하게 왜곡되지 않게 작게 배치하거나, 라벨이 잘 안 보이는 각도로 배치하세요.

[참고 이미지 역할]
- 상세 01: 제품 형태와 로즈 핑크 톤 참고. 라벨을 새로 쓰려 하지 말고, 제품 느낌만 참고.
- 상세 05, 06: 승인된 앞 컷. 폰트, 제목 크기, 여백, 로즈 핑크/화이트 톤을 맞추세요.
- 원본 상세 09: 사용 방법 문구 흐름 참고.

[스타일]
- 쿠팡 모바일 상세페이지용 780 x 1360 세로형
- 상단 짧은 텍스트 + 중하단 큰 라이프스타일 사진 느낌
- 밝은 욕실/화장대/화이트 타월/로즈 핑크 포인트
- 사람 얼굴, 눈, 입, 전신, 과한 피부 클로즈업 금지
- 깨끗한 손이 화장솜에 토닉 에센스를 덜거나 손등에 가볍게 얹는 장면
- 한국어 고딕/산세리프 계열, 명조체/세리프/붓글씨/손글씨 금지
- 자연스러운 실제 촬영 느낌 + 프리미엄 상세페이지 구성

[반드시 들어갈 한국어 텍스트 — 아래 문장을 그대로]

가볍게 시작하는 로즈 루틴

[금지]
- 사람 얼굴/모델 얼굴/눈/입/전신 금지
- 피부 전후 비교, 모공/잡티/홍조 등 문제 피부 클로즈업 금지
