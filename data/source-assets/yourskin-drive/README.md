# Yourskin Google Drive Asset Work Folders

Created: 2026-05-21

Source Google Drive folder: https://drive.google.com/drive/folders/1JHfueX2yODQ4X2BOOcsA3GlUfEkmyaQc

These folders mirror the current Coupang product set so product photos and generated images can be collected without changing the original Google Drive structure.

## Workspace Rules

- Keep each product's downloaded Drive originals inside its own `downloaded/` folder.
- Keep Drive folder names and original Korean file names as source evidence.
- Put new Drive folders named `...추가사진` beside the original product folder inside the same product's `downloaded/` folder.
- Do not put all product downloads under `aqua-lotion/downloaded/`; that folder is only for aqua lotion.
