## 2. 핵심 결론

### AI는 상품을 새로 만드는 도구가 아니다

원본 제품 사진은 반드시 기준 이미지로 둔다. AI는 배경, 연출 장면, 사용 상황, 섹션 분위기, 보조 컷을 만드는 데 쓰고, 실제 용기 모양/라벨/용량/패키지 문구는 바꾸면 안 된다.

유어스킨에 적용하면:
- 대표이미지: 실제 제품이 검색 결과에서 잘 보이는 것이 우선.
- 상세이미지: 제품 원본 + 사용 장면 + 성분/사용감 설명 + 신뢰 근거를 조합.
- AI 생성 이미지: 피부 개선 전후, 의학적 효과, 존재하지 않는 인증처럼 오해될 수 있는 이미지는 금지.

### 대표이미지와 상세이미지의 역할을 분리한다

대표이미지는 검색 결과에서 클릭을 만드는 이미지다. 제품, 용량, 핵심 카테고리가 작게 봐도 보여야 한다. 긴 카피, 성분 설명, 체크리스트는 대표이미지가 아니라 상세 2번 이후에 넣는다.

상세이미지는 구매 불안을 순서대로 제거하는 이미지다. 예쁜 이미지보다 아래 질문에 답해야 한다.

- 이 상품이 내 문제와 관련 있나?
- 왜 이 상품을 사야 하나?
- 용량/가격/구성은 납득되나?
- 성분과 사용감은 안전하게 이해되나?
- 제조/출고/고시정보를 믿을 수 있나?
- 지금 살 이유가 있나?

### 모바일 기준으로 만든다

쿠팡 상세는 모바일에서 먼저 본다. 한 컷에는 한 메시지만 넣고, 글자는 과감하게 줄인다.

권장 기준:
- 컷 폭: 780px 이상 기준으로 제작
- 한 컷 핵심 문장: 1개
- 보조 문장: 2줄 이하
- 글자 크기: 모바일에서 확대 없이 읽히는 크기
- 이미지 80%, 텍스트 20% 정도로 시작
- 긴 성분표/고시정보는 하단으로 분리

### 리뷰 언어를 상세페이지 언어로 쓴다

영상들에서 반복되는 포인트는 리뷰와 문의가 가장 좋은 카피 소스라는 점이다. 고객이 실제로 쓰는 표현을 먼저 모으고, 그 표현을 상세 첫 화면/FAQ/비교표에 반영한다.

예:
- 무겁지 않은 로션을 찾는 고객
- 대용량이라 가족이 같이 쓰기 좋다는 고객
- 클렌징 후 당김을 걱정하는 고객
- 끈적임 없는 사용감을 원하는 고객

이런 언어는 성분 설명보다 전환에 더 직접적으로 연결된다.

### 화장품은 표시광고 검수가 별도 에이전트로 필요하다

화장품 상세이미지에서 가장 위험한 것은 AI가 만들어낸 과장 문구다. 아래 표현은 특히 조심한다.

주의 표현:
- 치료, 개선, 재생, 회복, 완치
- 아토피, 여드름, 염증, 항균, 살균, 항암
- 줄기세포, 엑소좀, 진피층 전달
- 피부과 시술급, 약처럼 작용
- 전후 사진으로 의학적 변화 암시
- 수치 효과를 실증자료 없이 표현

안전한 방향:
- 피부 보습에 도움
- 산뜻한 사용감
- 데일리 수분 케어
- 세안 후 피부를 편안하게 정돈
- 건조함이 느껴지는 피부에 촉촉한 마무리
- 제조 6개월 이내 출고 같은 확인 가능한 사실

## 3. 추천 다중 에이전트 구조

### 1) 자료 정리 에이전트

역할:
- Google Drive 원본 이미지 폴더 확인
- 쿠팡 현재 등록 상품명/가격/용량/리뷰/이미지 매칭
- 제품별 원본 사진, 누끼, 상세 원본, 고시정보를 분리
- 누락 자료 표시

입력:
- Drive 폴더
- 쿠팡 URL
- 기존 제품 데이터
- 제품 원본 사진

출력:
- 제품별 작업 폴더
- asset-map.json
- 누락 자료 리스트
- 대표이미지 후보/상세이미지 후보 구분

유어스킨 현재 주의점:
- 수딩크림은 쿠팡에서 상세 이미지 원본이 아직 확보되지 않았다.
- 현재 확보한 6장은 상세 이미지가 아니라 상품 갤러리 이미지로 봐야 한다.
- 상세페이지 원본은 Wing 또는 Chrome 저장본 기준으로 별도 확보해야 한다.

### 2) 시장/경쟁 리서치 에이전트

역할:
- 쿠팡 내 경쟁 상품 5~10개 조사
- 가격, 리뷰 수, 대표이미지 구조, 상세 첫 3컷 분석
- 키워드와 고객 구매 이유 정리

출력:
- 경쟁 썸네일 패턴
- 가격/용량 포지션
- 리뷰에서 반복되는 구매 이유
- 유어스킨이 피해야 할 정면승부 지점
- 유어스킨이 밀어야 할 틈새 메시지

유어스킨 방향:
- 대형 브랜드와 감성/촬영 퀄리티로 정면승부하지 않는다.
- 대용량, 제조 신뢰, 실사용 루틴, 합리 가격, 세트 구성으로 포지션을 잡는다.

### 3) 리뷰/문의 분석 에이전트

역할:
- 자사 리뷰, 경쟁 리뷰, 문의를 모아 고객 언어를 추출
- 긍정 이유/불안 요소/반품 이유/FAQ 후보 정리

출력:
- 상세 상단에 넣을 고객 언어
- FAQ 10개
- 구매 전 불안 제거 문구
- 광고 소재 후보 문장

### 4) 상세 구조 설계 에이전트

역할:
- 제품별 상세이미지 컷 순서 설계
- 대표이미지와 상세이미지 역할 분리
- 각 컷의 메시지, 이미지 방향, 카피 길이 지정

기본 컷 순서:
1. 대표이미지: 제품 중심, 카테고리/용량이 보이는 검색용 이미지
2. 상세 1번: 첫 후킹, 누구를 위한 제품인지 3초 안에 전달
3. 상세 2번: 고객 문제 공감
4. 상세 3번: 핵심 장점 1개
5. 상세 4번: 용량/가격/사용 루틴
6. 상세 5번: 제형/사용감
7. 상세 6번: 성분 또는 원료 스토리
8. 상세 7번: 제조/출고/브랜드 신뢰
9. 상세 8번: 사용법
10. 상세 9번: 추천 대상/비추천 대상
11. 상세 10번: 고시정보/전성분/배송/교환

### 5) 카피라이팅 에이전트

역할:
- 각 컷의 제목, 보조 문장, CTA, FAQ 작성
- 쿠팡 검색 키워드와 상세페이지 언어 연결
- 과장 표현 없이 전환형 문장 작성

출력:
- 컷별 제목
- 컷별 보조 문장
- FAQ
- 대표이미지 문구 후보
- 광고 문구 후보

카피 원칙:
- 한 컷 한 메시지
- 성분명보다 구매 이유 먼저
- 확인 가능한 사실만 강하게
- 효능 표현은 약하게, 사용감/루틴/용량은 선명하게

### 6) 이미지 프롬프트 에이전트

역할:
- AI 이미지 생성용 프롬프트 작성
- 제품 원본이 변형되지 않도록 금지 조건 포함
- 컷별 배경/소품/조명/구도 제안

프롬프트 구조:
- 제품: 실제 원본 이미지를 기준으로 한 유어스킨플러스 제품
- 목적: 상세페이지 특정 컷의 역할
- 장면: 욕실, 화장대, 수분감 있는 흰색/그린톤 배경 등
- 조명: 부드러운 자연광, 깨끗한 스튜디오 조명
- 카메라: 50mm 제품 사진, 정면 또는 45도 각도
- 금지: 라벨 변경 금지, 용량 변경 금지, 새 문구 생성 금지, 피부 질환/치료 암시 금지

예시:
유어스킨플러스 히알루론산 토너 원본 제품 사진을 기준으로, 라벨과 병 모양을 유지한 채 깨끗한 화장대 위에 배치한다. 배경은 밝은 화이트와 연한 그린톤, 부드러운 자연광, 수분감 있는 투명한 물방울 소품을 사용한다. 의료적 효과나 피부 질환 표현은 넣지 않는다. 라벨 텍스트와 용량은 변경하지 않는다.

### 7) 디자인 에이전트

역할:
- Canva/Figma/HTML 템플릿에 이미지와 카피 배치
- 모바일 상세 컷으로 제작
- 제품별로 반복 가능한 레이아웃 시스템 유지

출력:
- 상세이미지 PNG/JPG
- 대표이미지 후보 3~5개
- 모바일 미리보기
- 쿠팡/스마트스토어 업로드용 최종 파일

디자인 원칙:
- 템플릿을 먼저 만든 뒤 제품별로 반복 적용
- 카드 과다 사용 금지
- 상세 첫 3컷은 구매 설득 중심
- 작은 화면에서 제품명과 핵심 문장이 먼저 보여야 함
- 배경은 브랜드 톤을 유지하되 제품이 묻히면 안 됨

### 8) 표시광고 검수 에이전트

역할:
- 화장품법/표시광고 리스크 검토
- 위험 문구를 안전한 대체 문구로 변경
- 실증자료가 필요한 문장 표시

출력:
- 위험 문구 목록
- 위험도: 낮음/중간/높음
- 수정 제안
- 증빙 필요 자료

검수 기준:
- 의약품처럼 보이는 표현 제거
- 기능성화장품 범위를 넘는 표현 제거
- 전후 사진으로 치료/개선 암시 금지
- 인증/수상/테스트는 실제 자료가 있을 때만 사용
- PDRN, 히알루론산, 나이아신아마이드 등 성분은 효능 과장 없이 설명

### 9) 모바일 QA 에이전트

역할:
- 모바일 화면에서 글자 크기, 크롭, 이미지 깨짐 확인
- 상품명/용량/가격/고시정보 일치 확인
- 대표이미지와 상세이미지 역할 혼동 확인

체크리스트:
- 모바일에서 확대 없이 제목이 읽히는가
- 첫 3초 안에 제품/장점/대상이 보이는가
- 용량이 실제 상품과 맞는가
- 원본 라벨이 왜곡되지 않았는가
- 상세이미지에 과장 표현이 없는가
- 고시정보와 전성분이 누락되지 않았는가
- 쿠팡 썸네일로 작게 봐도 제품이 보이는가

### 10) 저장/업로드 에이전트

역할:
- 최종 파일을 폴더에 정리
- 생성에 사용한 프롬프트와 카피, 검수 결과를 함께 보관
- 쿠팡/스마트스토어 업로드 상태 기록

권장 폴더 구조:
- 00-source: 원본 제품 사진, 기존 상세 원본
- 01-research: 경쟁 분석, 리뷰 분석
- 02-copy: 컷별 카피, FAQ
- 03-prompts: 이미지 생성 프롬프트
- 04-drafts: 시안
- 05-compliance: 검수 기록
- 06-final: 업로드용 최종 이미지
- 07-upload-log: 업로드 일자, 플랫폼, 변경 사항

## 4. 유어스킨 첫 실행안

### 우선순위 1: 히알루론산 토너

이유:
- 500ml 대용량이라는 명확한 차별점이 있다.
- 기존 문서에서 상세페이지 구조와 카피보드가 이미 많이 정리되어 있다.
- 대표이미지와 상세이미지 역할 분리가 필요한 상태다.
- 쿠팡 경쟁이 강하므로 첫 상세 개선 테스트 상품으로 적합하다.

첫 작업:
1. 기존 상세 8장과 원본 제품 사진을 자료 정리 에이전트가 확정
2. 경쟁 토너 10개 대표이미지/상세 첫 3컷 분석
3. 리뷰 언어 기반으로 첫 3컷 카피 재작성
4. 대표이미지는 제품 중심 3안 제작
5. 상세 2~5번 컷만 먼저 제작해서 빠르게 교체 테스트
6. 표시광고 검수 후 업로드

### 우선순위 2: 수딩크림

이유:
- Leo가 새로 URL을 준 상품이고 쿠팡 등록 상태가 확인됐다.
- 현재 확보된 이미지는 상품 갤러리 이미지이며 상세 이미지 원본은 미수집 상태다.
- 상세이미지를 새로 만들기 전에 기존 상세 원본 확보가 먼저다.

첫 작업:
1. Wing 또는 Chrome 저장본으로 상세 원본 확보
2. 현재 갤러리 6장과 상세 원본을 분리
3. PDRN/히알루론산 표현의 표시광고 위험도 검수
4. 수딩, 진정, 재생 같은 표현은 안전 문구로 대체
5. 대표이미지 3안, 상세 첫 5컷부터 제작

### 우선순위 3: 클렌징 오일 + 클렌징 젤 세트

이유:
- 세트 구성으로 객단가를 올리기 좋다.
- 사용 루틴을 이미지로 설명하기 쉽다.
- 리뷰/문의 기반 FAQ를 만들기 좋다.

첫 작업:
1. 클렌징 루틴 경쟁 상품 분석
2. 사용 순서 이미지 설계
3. 오일과 젤의 역할 차이를 한 화면에 설명
4. 세트 구매 이유와 단품 구매 이유를 분리

## 5. 자동화할 때의 최소 입력값

제품별로 아래 데이터가 있어야 에이전트가 안정적으로 상세이미지를 만든다.

필수:
- 상품명
- 용량
- 가격
- 원본 제품 사진
- 현재 쿠팡 URL
- 현재 상세 이미지 또는 Wing 상세 원본
- 전성분/고시정보
- 기능성화장품 여부
- 사용 가능한 인증/테스트 자료

권장:
- 경쟁 상품 5~10개 URL
- 자사 리뷰
- 경쟁 리뷰
- 반품/문의 내역
- 제조일/출고 정책
- 브랜드 로고 원본
- 패키지 라벨 원본

없으면 안 되는 것:
- 원본 제품 사진
- 실제 용량/가격
- 고시정보
- 표시광고 검수

## 6. 실제 운영 순서

1. 제품 하나를 고른다.
2. 자료 정리 에이전트가 원본/현재 등록 상태/누락 자료를 정리한다.
3. 리서치 에이전트가 경쟁 상품과 리뷰 언어를 뽑는다.
4. 상세 구조 설계 에이전트가 컷 순서를 만든다.
5. 카피 에이전트가 컷별 문장을 쓴다.
6. 표시광고 검수 에이전트가 위험 문구를 먼저 제거한다.
7. 이미지 프롬프트 에이전트가 컷별 생성 프롬프트를 만든다.
8. 디자인 에이전트가 템플릿에 배치한다.
9. 모바일 QA 에이전트가 크롭/가독성/오탈자를 확인한다.
10. 저장/업로드 에이전트가 최종 파일과 기록을 폴더에 정리한다.

## 7. 결론

유어스킨 상세이미지는 에이전트 여러 개를 병렬로 쓰되, 역할을 섞으면 안 된다. 이미지 생성 에이전트가 카피와 법적 표현까지 책임지게 하면 위험하다.

가장 안전한 조합:
- 리서치 에이전트: 무엇을 말해야 하는지 결정
- 카피 에이전트: 어떻게 짧게 말할지 결정
- 이미지 프롬프트 에이전트: 어떤 장면을 만들지 결정
- 디자인 에이전트: 모바일 상세 컷으로 배치
- 표시광고 검수 에이전트: 위험 표현 제거
- QA 에이전트: 업로드 전 오류 확인

첫 실행은 히알루론산 토너로 하는 것이 맞다. 이미 자료와 전략 문서가 쌓여 있고, 500ml 대용량/제조 신뢰/데일리 보습 루틴이라는 메시지를 안전하게 테스트할 수 있다.
