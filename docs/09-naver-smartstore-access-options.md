# 09. Naver SmartStore Detail Access Options

확인일: 2026-05-11

Leo 요청: 네이버 스마트스토어 상품 상세 페이지에 접근할 수 있는 방법 모색.

## 현재 증상

대상 예시:

```text
https://smartstore.naver.com/main/products/12763872443
https://smartstore.naver.com/yourskinplus/products/12763872443
https://m.smartstore.naver.com/yourskinplus/products/12763872443
```

Codex/OpenClaw 실행 환경에서 직접 접근 시 다음 중 하나가 발생한다.

- HTTP 490 + captcha HTML
- HTTP 429 + 네이버 시스템오류/접속 제한 화면
- HTTP 302 후 네이버 로그인 페이지
- 네이버 쇼핑 도메인 일부는 HTTP 418 응답

헤더 변경, 모바일 User-Agent, 네이버 앱 User-Agent, 검색페이지 referer, `curl_cffi` TLS impersonation까지 테스트했지만 상세 HTML 확보에는 실패했다.

## 확인된 정상 공개 경로

### 1. 네이버 통합검색 초기 데이터 활용 — 현재 가장 안정적

아래 URL은 접근 가능하다.

```text
https://search.naver.com/search.naver?query=유어스킨플러스
```

이 HTML 내부의 JS 초기 상태에서 다음 데이터를 추출할 수 있다.

- 상품명
- 스마트스토어 상품 ID (`channelProductId`)
- 네이버 쇼핑 ID (`nvMid`)
- 정가/할인가/할인율
- 리뷰 수/평점
- 대표 이미지 URL
- 카테고리 ID
- 판매자명/스토어 ID
- 상품 상세 URL

한계:

- 상세페이지 본문 이미지/상세 설명 HTML은 없음
- 옵션/배송 상세/고시정보/리뷰 본문까지는 부족

### 2. 사용자의 일반 브라우저에서 수동 저장

가장 확실한 방법.

Leo 또는 매형 PC/폰에서 상세 페이지를 열고:

- 브라우저 `페이지 소스 저장` 또는 `다른 이름으로 저장`
- 개발자도구 Network에서 JSON/XHR export
- 상세 이미지 영역 캡처/저장

그 파일을 프로젝트에 넣으면 AI가 상세페이지 구조/카피/이미지/리뷰를 분석할 수 있다.

추천 저장 위치:

```text
data/naver/raw/{productId}.html
data/naver/raw/{productId}.har
```

### 3. 스마트스토어센터/커머스API — 소유자 접근 가능하면 최선

매형이 스토어 운영자라면 공개 크롤링보다 이 경로가 가장 깨끗하다.

가능한 방법:

- 스마트스토어센터 상품관리에서 상품 정보 다운로드/복사
- 네이버 커머스API 사용 권한 발급 후 상품 정보 조회
- 상세페이지 이미지/상세설명 원본 확보

장점:

- 차단 없음
- 상품 설명 원본 확보 가능
- 옵션/재고/가격/고시정보까지 정확

단점:

- 판매자 계정 권한 필요
- API 사용 시 인증 세팅 필요

### 4. 실제 브라우저 자동화 + 로그인 세션

OpenClaw 서버의 headless 요청은 차단되므로, 정상 브라우저 세션을 사용하는 방식.

조건:

- Mac/PC에 Chrome 또는 Safari 실제 브라우저 사용
- 네이버 캡차/로그인 필요 시 사람이 직접 처리
- 이후 세션 쿠키가 있는 상태에서 HTML 저장

주의:

- 네이버 보안 정책 우회가 아니라, 사람이 로그인/캡차를 처리한 정상 세션에서 백업하는 방식이어야 한다.
- 계정 쿠키를 코드/레포에 저장하면 안 된다.

## 추천 전략

1. 지금 당장 필요한 가격/목록/대표 이미지는 `네이버 통합검색 초기 데이터`로 계속 수집한다.
2. 상세페이지 본문/이미지가 필요하면 Leo가 브라우저에서 HTML 또는 HAR를 한 번 저장해서 전달한다.
3. 장기적으로는 매형이 스마트스토어 운영자라면 스마트스토어센터/커머스API 권한으로 원본 데이터를 받는 게 가장 안정적이다.

## 결론

현재 OpenClaw 실행 환경 단독으로 스마트스토어 상세 HTML을 안정적으로 가져오는 방법은 확인되지 않았다. 네이버가 상세 페이지 접근에 captcha/login/rate-limit를 걸고 있다.

하지만 네이버 통합검색 초기 데이터는 접근 가능하므로 상품 목록/가격/대표이미지 수준은 자동 수집 가능하다. 상세페이지 원문 분석은 사용자 브라우저 저장본 또는 판매자 권한 기반 접근으로 진행하는 것이 안전하고 현실적이다.
