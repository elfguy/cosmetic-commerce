# 29. 쿠팡 등록 제품 순차 개선 로드맵

작성일: 2026-06-05 KST  
대상: 유어스킨플러스 쿠팡 등록 상품 11개  
목적: 아쿠아 로션 V4 작업에서 얻은 노하우를 기준으로, 나머지 쿠팡 등록 제품을 어떤 순서와 방식으로 개선할지 정리한다.

## 1. 결론

나머지 제품은 **예쁜 상세페이지를 하나씩 만드는 순서**가 아니라, 쿠팡에서 판매 가능성이 높은 상품군부터 개선해야 한다.

| 순서 | 제품 | 개선 우선도 | 이유 |
|---:|---|---|---|
| 1 | 히알루론산 토너 500ml | 최상 | 대용량·수분·스킨팩 키워드가 명확하고, 아쿠아 로션과 세트 판매 가능성이 높음 |
| 2 | 퓨어 딥 클렌징 오일 300ml | 최상 | 클렌징 오일은 검색 의도와 사용 장면이 뚜렷하고, 클렌징 젤과 세트 구성 가능 |

핵심 방향:

1. **수분 루틴 축**: 토너 → 아쿠아 로션 → 수딩 크림 → 앰플
2. **클렌징 루틴 축**: 클렌징 오일 → 클렌징 젤

## 2. 현재까지 얻은 핵심 노하우

### 2.1 쿠팡 대표이미지와 상세이미지는 목적이 다르다

대표이미지 1번은 상세페이지 hero가 아니다.

대표이미지 1번의 목적:

- 검색 결과에서 제품을 알아보게 하기
- 썸네일에서 깨끗하고 신뢰감 있게 보이기
- 제품 라벨/용량/형태가 잘 보이게 하기
- 긴 문구, 성분 카드, 배너형 디자인을 피하기

권장 형태:

```text
흰색 또는 밝은 배경 + 실제 제품 크게 + 최소한의 신뢰 배지 0~1개
```

상세이미지의 목적:

- 구매자가 가진 질문을 순서대로 해소하기
- 왜 이 제품을 사야 하는지 설명하기
- 사용 장면, 용량, 제조 신뢰, 성분 근거, 사용법, 전성분을 보여주기

### 2.2 상세 첫 3컷이 판매 설득의 핵심이다

쿠팡 모바일에서는 상세를 끝까지 보지 않는다. 첫 3컷에서 다음이 보여야 한다.

| 컷 | 역할 | 예시 |
|---:|---|---|
| 1 | 한 줄 구매 이유 | `매일 아끼지 않고 쓰는 500ml 수분 토너` |
| 2 | 문제 공감/사용 장면 | `닦토·흡토·스킨팩까지 넉넉하게` |
| 3 | 신뢰 근거 | `제조 6개월 이내 제품 보장`, `직접 제조`, `용량/가격 장점` |

성분 설명은 중요하지만, 너무 초반부터 성분명만 나열하면 구매자가 지루해진다. **초반은 사용 이유와 구매 이유**, 중반은 성분/근거, 후반은 사용법/전성분/고시정보가 좋다.

### 2.3 GPT Images 작업 원칙

아쿠아 로션 V4 작업에서 검증된 원칙:

1. **한 번에 15장 만들기보다 순차 제작이 안정적**이다.
2. 컷별로 `목적`, `필수 문구`, `금지 문구`, `참조 이미지 역할`을 나눠야 한다.
3. 제품명 드리프트는 즉시 불합격 처리한다.
4. 작은 한국어 오탈자는 가볍게 넘기지 않는다.
5. 사용자가 승인한 구도는 `composition lock`으로 취급한다.
6. GPT Images 품질이 필요한 컷은 로컬 합성으로 대체하지 않는다.
7. 단, 전성분/표/고시정보처럼 작은 글자가 많은 컷은 deterministic typography를 검토할 수 있다.

### 2.4 쿠팡 라이브 반영 원칙

로컬에서 완성했다고 끝이 아니다. 라이브 쿠팡 반영까지 확인해야 한다.

필수 절차:

1. 현재 쿠팡 상품 JSON 백업
2. 대표/상세 이미지 업로드
3. Rocket Growth 필드 보존
4. PUT 후 OpenAPI 재조회
5. `statusName` 확인
6. `items[].images[]`, `items[].contents[]` 카운트 확인
7. `contentDetails[].content`가 `vendor_inventory/...` CDN으로 변환됐는지 확인
8. CDN URL 200 확인
9. 필요한 경우 쿠팡 화면/앱 캐시 이슈 확인

주의:

- `localtunnel`은 로컬에서는 200이어도 쿠팡 ingestion에서 문제가 생길 수 있다.
- 상세 이미지 cache busting이 필요하면 Python 정적 서버 + Cloudflare tunnel로 외부 200 확인 후 사용한다.
- PUT 성공만 보고 끝내면 안 된다. 반드시 재조회해서 `vendor_inventory` 변환 여부를 확인해야 한다.

## 3. 개선 우선순위 상세

## 3.1 1순위 — 히알루론산 토너 500ml

쿠팡 URL:

```text
https://www.coupang.com/vp/products/9025733014?itemId=26470069791&vendorItemId=93445228832
```

### 왜 먼저 해야 하나

토너는 현재 전체 제품군에서 가장 좋은 주력 후보 중 하나다.

강점:

- `히알루론산 토너`, `수분 토너`, `대용량 토너`, `스킨팩`, `닦토` 키워드 대응 가능
- 500ml 대용량이 명확한 차별점
- 아쿠아 로션과 바로 세트 구성 가능
- 상세페이지 스토리 만들기 쉬움

### 핵심 포지션

```text
오래된 재고 걱정 없이, 매일 아끼지 않고 쓰는 500ml 대용량 수분 토너
```

### 대표이미지 방향

- 1번: 제품 단독, 흰 배경, 텍스트 최소화
- 2번 이후: 500ml 대용량, 제조 6개월 이내, 닦토/흡토/스킨팩 사용 장면

### 상세 컷 구성 예시

1. 매일 아끼지 않고 쓰는 500ml 수분 토너
2. 닦토·흡토·스킨팩까지 넉넉하게
3. 제조 6개월 이내 제품 보장
4. 세안 후 첫 수분 루틴
5. 히알루론산 수분 컨셉
6. 화장솜/스킨팩 사용 장면
7. 대용량 가격 장점
8. 직접 제조/신선 출고 신뢰
9. 추천 피부/사용 상황
10. 사용법
11. 함께 쓰면 좋은 아쿠아 로션
12. 전성분/고시정보

### 완료 기준

- 대표이미지 6장
- 상세이미지 12~15장
- 쿠팡 라이브 반영 전 rollback 준비
- 광고 키워드 후보 20개 정리

## 4. 제품별 공통 작업 프로세스

각 제품은 아래 순서로 진행한다.

### Step 1. 현재 상태 백업/수집

- 쿠팡 OpenAPI 상품 JSON 조회
- 기존 대표이미지/상세이미지 저장
- 기존 상세 이미지 수, 내용, 위험 표현 확인
- 상품명, 가격, 용량, 리뷰 수, 카테고리 확인
- 롤백 폴더 준비

완료 산출물:

```text
data/coupang/rollback/<product-slug>/<timestamp>/current-product-response.raw.json
```

### Step 2. 경쟁 상품 5~10개 조사

조사 기준:

- 같은 카테고리 인기 상품
- 가격/용량/리뷰 수
- 대표이미지 스타일
- 상품명 키워드
- 상세 첫 3컷 구조
- 우리가 이길 수 있는 틈

정면승부 피하기:

- 리뷰 수 많은 대형 브랜드와 감성/성분 브랜딩으로 정면승부하지 않는다.
- 유어스킨플러스는 **대용량, 직접 제조, 제조 6개월 이내, 합리 가격, 데일리 실사용** 쪽으로 우회한다.

### Step 3. 상품 포지션 확정

각 제품마다 한 문장으로 정리한다.

형식:

```text
[누가/언제] [무엇을 위해] 쓰는 [핵심 키워드] 제품
```

예시:

```text
세안 후 첫 단계에서 아끼지 않고 쓰는 500ml 대용량 수분 토너
```

### Step 4. 상품명/키워드 후보 작성

상품명은 다음 구조를 우선한다.

```text
브랜드명 + 핵심 성분/기능 키워드 + 제품군 + 용량 + 구매 이유/사용 장면
```

예시:

```text
유어스킨플러스 히알루론산 토너 500ml 대용량 수분 토너 닦토 스킨팩
```

주의:

- 쿠팡 정책 위반 가능성이 있는 과장 키워드 금지
- 인증/시험 근거 없는 `저자극`, `천연`, `무자극` 남발 금지
- 상품명은 변경 전 사용자 승인 필요

### Step 5. 대표이미지 6장 설계

권장 구성:

| 슬롯 | 역할 |
|---:|---|
| 01 | 제품 인식용 메인 이미지. 흰 배경, 제품 크게, 텍스트 최소화 |
| 02 | 핵심 구매 이유 1개 |
| 03 | 사용 장면/루틴 |
| 04 | 용량/가격/실용성 |
| 05 | 제조 신뢰/신선 보장 |
| 06 | 세트/추천 대상/사용법 요약 |

### Step 6. 상세이미지 12~15장 설계

권장 흐름:

1. Hero: 한 줄 구매 이유
2. 문제 공감: 이 제품이 필요한 상황
3. 핵심 차별점: 용량/신선/직접 제조/사용감
4. 사용 장면: 실제 쓰는 방법
5. 성분 컨셉: 과장 없는 성분 설명
6. 제형/텍스처
7. 루틴 제안
8. 추천 대상
9. 제조/품질 신뢰
10. 사용법
11. 함께 쓰면 좋은 제품
12. 전성분/고시정보

### Step 7. 제작/검수

검수 항목:

- 제품명이 정확한가
- 용량이 정확한가
- 한국어 오탈자가 없는가
- 금지 표현이 없는가
- 숫자/컷 번호/POINT 번호가 이미지 안에 불필요하게 들어가지 않았는가
- 실제 제품과 라벨이 맞는가
- 제품 병/펌프/제형이 이상하지 않은가
- 상세 첫 3컷만 봐도 구매 이유가 보이는가

### Step 8. 로컬 등록/빌드/미리보기

- `public/coupang/images/<product>/versions/v1` 또는 `v4` 등 버전 폴더 구성
- manifest 업데이트
- 비교 페이지 또는 작업 페이지 업데이트
- `npm run build` 실행
- 직접 이미지 URL 200 확인

### Step 9. 쿠팡 라이브 반영

상품 변경 작업은 사용자 승인 후 진행한다.

필수 체크:

- 롤백 백업 존재
- 대표이미지/상세이미지 수 확인
- PUT payload에서 기존 필수 필드 유지
- Rocket Growth 관련 필드 유지
- 반영 후 OpenAPI 재조회
- `statusName = 승인완료` 확인
- `contentDetails[].content`가 `vendor_inventory/...`로 변환됐는지 확인
- CDN 200 확인

### Step 10. 7일 광고/판매 데이터 관찰

상세 개선 후 바로 성공/실패를 단정하지 않는다.

7일간 볼 지표:

| 지표 | 해석 |
|---|---|
| 노출수 | 상품명/키워드/광고 세팅 문제 |
| 클릭률 | 대표이미지/상품명/가격 문제 |
| 전환율 | 상세 첫 3컷/리뷰/가격/배송 문제 |
| 광고 검색어 | 실제 구매 의도 키워드 후보 |
| 주문수 | 최종 판매성 |
| 리뷰 증가 | 장기 랭킹 기반 |

## 7. 세트 상품 전략

월 매출을 키우려면 단품만으로는 어렵다. 단품은 유입, 세트는 객단가를 만든다.

### 우선 세트 후보

| 순서 | 세트 | 구성 | 역할 |
|---:|---|---|---|
| 1 | 대용량 수분 루틴 2종 | 토너 + 아쿠아 로션 | 가장 먼저 만들 세트 |
| 2 | 순한 클렌징 2종 | 클렌징 오일 + 클렌징 젤 | 사용 루틴이 명확한 세트 |
| 3 | 수분 보습 3단계 | 토너 + 아쿠아 로션 + 수딩 크림 | 객단가 상승 |
| 4 | 데일리 스킨케어 3종 | 클렌징 젤 + 토너 + 로션 | 초보자용 기본 루틴 |
| 5 | 가족/선물 세트 | 토너 + 로션 + 클렌징 오일 + 립밤 | 스마트스토어/선물용 |

### 세트 상세페이지 원칙

- 단품 상세를 붙여넣지 않는다.
- “왜 같이 써야 하는지”를 먼저 보여준다.
- 루틴 순서 이미지를 만든다.
- 객단가가 높아지는 만큼 가격 이점/사용 기간/가족 사용 장면을 보여준다.
