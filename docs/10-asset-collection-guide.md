# 10. 유어스킨 상세페이지/상품 이미지 수집 가이드

확인일: 2026-05-11

목적: 유어스킨 기존 스마트스토어 상세페이지와 상품 이미지를 확보해서 상세페이지 고도화, 브랜드 사이트, 제품별 랜딩페이지 제작에 활용한다.

## 전제

- 유어스킨은 Leo의 누나가 만든 브랜드.
- 네이버 스마트스토어 상품 등록도 누나가 직접 진행.
- 따라서 무리한 크롤링보다 **원본 자료를 운영자 권한으로 받는 방식**이 가장 빠르고 안전하다.

## 누나에게 요청할 자료

### 1. 상품별 기본 자료

각 상품마다 아래를 받는다.

- 상품명
- 용량/가격/할인가
- 대표 이미지 원본
- 추가 상품 이미지 원본
- 상세페이지 이미지 원본
- 상세페이지 문구/HTML 또는 편집 원본
- 전성분/기능성 고시/주의사항
- 제조사/책임판매업자/품질보증 문구
- 배송/교환/반품 안내
- 기존 리뷰 캡처 또는 리뷰 요약

### 2. 이미지 원본

가능하면 압축 파일로 받는다.

권장 구조:

```text
yourskin-assets/
  12763872443-aqua-lotion/
    main/
    detail/
    package/
    ingredient/
  12597599110-hyaluronic-toner/
    main/
    detail/
    package/
    ingredient/
```

파일명은 한글이어도 되지만, 사이트 제작용으로는 나중에 영문 slug로 정리한다.

### 3. 스마트스토어센터에서 받을 수 있으면 좋은 것

스마트스토어센터 > 상품관리에서 가능한 방식:

- 상품 상세 수정 화면의 상세설명 HTML 복사
- 상세 이미지 원본 다운로드
- 상품 정보 엑셀 다운로드
- 상품별 URL 목록
- 옵션/재고/배송비 설정 캡처

## Leo가 누나에게 보내면 좋은 요청 문구

```text
누나, 유어스킨 제품 상세페이지랑 상품 이미지 고도화해서 별도 브랜드 사이트도 만들어보려고 해.
스마트스토어에 올린 상품별로 아래 자료 받을 수 있을까?

1) 대표 이미지 원본
2) 상세페이지 이미지 원본
3) 상세페이지 문구나 HTML 원본
4) 제품명/용량/가격/전성분/주의사항
5) 가능하면 스마트스토어 상품관리에서 상품정보 엑셀 다운로드한 파일

상품별 폴더로 압축해서 주면 제일 좋아.
기존 거 그대로 베끼려는 게 아니라, 그걸 기반으로 더 예쁘고 전환 잘 되게 리디자인하려고 해.
```

## 우리가 할 작업 흐름

1. 원본 자료 수집
2. 상품별 자산 폴더 정리
3. 기존 상세페이지 구조 분석
4. 상세페이지 고도화 방향 설계
   - 첫 화면 후킹
   - 피부 고민/타겟 명확화
   - 성분 신뢰 요소
   - 사용감/제형 설명
   - 후기/FAQ/CTA
5. 공식 사이트 제품 데이터 구조화
6. 제품별 상세페이지/랜딩페이지 제작
7. 스마트스토어 구매 CTA 연결
8. 이후 자체 결제/리드 수집 확장 검토

## 우선순위

1. 히알루론산 아쿠아 로션
2. 저분자 히알루론산 토너
3. 저자극 클렌징오일
4. 약산성 클렌징젤
5. 장미에센스/화이트닝크림/수딩크림 등 가격비교 노출 상품

## 주의

- 원본 이미지/상세 설명은 가족 브랜드 자료라도 레포 공개 여부를 조심한다.
- 외부 공개 전에는 누나에게 최종 확인을 받는다.
- 화장품 효능 표현은 과장 광고 리스크가 있으므로 `치료`, `완치`, `재생`, `염증 개선` 같은 표현은 피하고, 기능성 인증 범위 안에서 표현한다.
