# 18. AI 에이전트 기반 마케팅 운영 계획

확인일: 2026-05-17

목적: 유어스킨플러스 제품을 실제로 더 잘 팔기 위해 여러 AI 에이전트 관점으로 채널, 상품, 전환, 표시광고 리스크, 운영 자동화를 통합해 30일 실행안을 정한다.

## 최종 결론

현재 상황에서 가장 좋은 전략은 단품 광고 확장이 아니다. 리뷰 수가 23~34개 수준이고 경쟁 상품은 수천~수십만 리뷰를 갖고 있으므로, 리뷰 신뢰 싸움을 정면으로 하기 어렵다.

따라서 첫 30일은 아래 3가지를 우선한다.

1. `클렌징 듀오 세트`: 퓨어 딥 클렌징 오일 300ml + 로우 피에이치 클렌징 젤 300ml
2. `대용량 수분 루틴 세트`: 히알루론산 토너 500ml + 아쿠아 로션 300ml
3. `화이트닝 톤 케어 크림`: 200ml 미백 기능성 단품, 단 효능 과장 없이 기능성 범위 안에서 운영

AI는 카피를 많이 찍어내는 도구가 아니라, 상품 자료를 고정하고, 문구를 검사하고, 소재를 변형하고, 광고/리뷰 성과를 읽어 다음 실험을 제안하는 운영 시스템으로 써야 한다.

## 에이전트 논의 요약

| 에이전트 | 결론 | 운영 반영 |
|---|---|---|
| 채널 전략 | 네이버 쇼핑/검색, 쿠팡 소액 광고, 블로그/SEO가 우선. Meta는 리타겟팅/소재 테스트 보조 | 구매 의도 검색을 먼저 잡고, 소셜은 냉유입 대량 집행 금지 |
| 상품/전환 | 단품보다 세트로 객단가를 2만원 이상으로 올려야 함 | 클렌징 듀오, 수분 루틴 세트, 톤 케어 크림 순서로 랜딩 제작 |
| AI 운영 | 에이전트 조직과 주간 루프가 필요함 | 상품 데이터, 경쟁 스냅샷, 콘텐츠, 광고 성과, 리뷰를 주 단위로 순환 |
| 표시광고/신뢰 | 기능성 2개 제품만 기능성 표현 허용. 나머지는 사용감/루틴/성분 투명성 중심 | 모든 카피는 AI 1차 검사 후 사람 승인 |

## 주력 상품과 세트

### 1순위: 클렌징 듀오 세트

구성:

- 퓨어 딥 클렌징 오일 300ml
- 로우 피에이치 클렌징 젤 300ml

예상 판매가:

- 19,900원~21,900원

첫 화면 메시지:

> 300ml + 300ml, 선크림부터 세안 후 당김까지 한 번에 관리하는 대용량 클렌징 루틴

보조 메시지:

> 오일로 지우고, 약산성 젤로 마무리. 매일 쓰는 클렌징은 용량과 사용감이 중요합니다.

운영 이유:

- 두 제품 모두 대용량이고 단위가 경쟁력이 있다.
- 클렌징 오일 단품보다 젤 클렌저를 묶는 이유가 자연스럽다.
- 유화 사용법, 1차/2차 세안 콘텐츠를 만들기 쉽다.

### 2순위: 대용량 수분 루틴 세트

구성:

- 히알루론산 토너 500ml
- 아쿠아 로션 300ml

예상 판매가:

- 17,900원~19,900원

첫 화면 메시지:

> 500ml 토너와 300ml 로션으로 아끼지 않고 쓰는 데일리 수분 루틴

운영 이유:

- 라운드랩 독도 토너+로션 세트와 비교 가능한 구조다.
- 토너 218원/10ml, 로션 327원/10ml로 가격 효율을 설명하기 쉽다.
- 스킨팩, 샤워 후 로션, 아침/저녁 수분 루틴 콘텐츠로 확장 가능하다.

### 3순위: 화이트닝 톤 케어 크림

구성:

- 화이트닝 톤 케어 크림 200ml

예상 판매가:

- 단품 10,100원 유지 또는 토너 묶음 18,900원~20,900원

첫 화면 메시지:

> 나이아신아마이드 기능성 기반, 매일 바르는 200ml 톤 케어 크림

운영 이유:

- 미백 기능성 고시 범위를 사용할 수 있다.
- 200ml 대용량과 505원/10ml 단가가 좋다.
- 단, 즉시 미백, 잡티 제거, 기미 제거 같은 표현은 금지한다.

## 업셀과 증정

| 조건 | 제안 | 목적 |
|---|---|---|
| 19,900원 이상 | 립밤 추가 4,900원 | 객단가 보조 |
| 29,900원 이상 | 립밤 증정 | 3종 번들 전환 |
| 클렌징 오일 단품 | 젤 클렌저 함께 구매 시 세트 할인 | 루틴 전환 |
| 토너 단품 | 로션 함께 구매 시 수분 루틴가 | 세트 전환 |
| 톤 케어 크림 | 토너와 함께 쓰는 톤 케어 루틴 제안 | 기능성 단품 보완 |

립밤은 단품 광고 주력 상품으로 쓰지 않는다. 세트 증정, 장바구니 추가, 선물 보조 상품으로 운영한다.

## 채널 우선순위

| 순위 | 채널 | 30일 역할 | 예산 가이드 |
|---:|---|---|---:|
| 1 | 네이버 쇼핑/검색 | 구매 의도 키워드에서 세트/주력 상품 반응 확인 | 100만~140만원 |
| 2 | 쿠팡 광고 | 쿠팡 내 기존 탐색 고객 대상으로 소액 검증 | 60만~90만원 |
| 3 | 블로그/SEO | 사용법, 성분, 비교 콘텐츠로 검색 신뢰 축적 | 40만~70만원 |
| 4 | Meta/Instagram | 짧은 영상 소재 테스트와 리타겟팅 | 30만~60만원 |
| 5 | B2B 샘플 | 피부관리실, 샵, 소형 리셀러 테스트 | 20만~40만원 |
| 6 | 카카오채널 | 구매 후 재구매/상담 CRM | 세팅만 우선 |

첫 30일 광고비는 250만~350만원 범위에서 시작한다. 제품 샘플, 배송비, 촬영비는 별도로 본다.

- 쿠팡에서 토너, 로션, 클렌징오일 같은 광범위 키워드 정면 경쟁
- 카카오채널 친구 모으기 광고

## AI 에이전트 조직

```text
AI 마케팅 총괄 에이전트
├─ 상품 데이터 관리자
├─ 경쟁/시장 리서치 에이전트
├─ 콘텐츠 기획/생성 에이전트
├─ 광고 소재 변형 에이전트
├─ 클레임/표시광고 검사 에이전트
├─ 리뷰/문의 분석 에이전트
├─ 상세페이지 개선 에이전트
├─ 성과 분석/주간 리포트 에이전트
└─ 사람 검수자
```

| 역할 | 입력 | 산출물 | 주기 |
|---|---|---|---|
| 상품 데이터 관리자 | 상품명, 가격, 성분, 이미지, URL | 검증된 상품 마스터 | 변경 시 |
| 경쟁 리서치 | 쿠팡 경쟁 상품, 리뷰, 가격, 월 구매 신호 | 경쟁 변화 요약 | 주 1회 |
| 콘텐츠 기획/생성 | 상품 마스터, 안전 문구, 고객 질문 | 블로그, 릴스 스크립트, 카드뉴스 문안 | 주 2~3회 |
| 광고 소재 변형 | 승인된 카피, 제품 사진, 세트 제안 | 광고 카피, 썸네일 문구, A/B 후보 | 주 1회 |
| 클레임 검사 | 모든 카피와 이미지 문구 | 사용 가능/수정 필요/사용 금지 판정 | 발행 전 |
| 리뷰/문의 분석 | 리뷰 원문, 문의, 반품/불만 | 고객 언어, FAQ, 상세페이지 보강점 | 주 1회 |
| 상세페이지 개선 | 경쟁 분석, 리뷰 요약, 이미지 분석 | 첫 화면 문구, 섹션 개선안, FAQ | 격주 |
| 주간 리포트 | 광고비, 클릭, 매출, 콘텐츠 성과 | 다음 주 액션 5개 | 매주 월요일 |

## 주간 운영 루프

### 월요일: 성과 리포트

- 광고비, 클릭수, 장바구니, 구매, 리뷰, 문의, 콘텐츠 조회수 입력
- AI가 잘 된 것, 버릴 것, 다음 실험을 정리
- 사람은 예산 이동과 문구 리스크만 최종 판단

### 화요일: 콘텐츠/광고 후보 생성

- 토너, 클렌징 오일, 클렌징 젤, 톤 케어 크림 중심
- 제품별 블로그 주제, 릴스 스크립트, 광고 카피 후보 생성
- 립밤은 증정/세트 보조 문구로만 생성

### 수요일: 클레임 검사

- 자동 차단 키워드 검사
- 기능성 제품과 일반 제품을 구분
- `사용 가능`, `수정 필요`, `사용 금지`로 판정

### 목요일: 발행/광고 세팅

- 승인된 소재만 네이버, 쿠팡, 인스타그램, 블로그에 배치
- 첫 달은 전 상품이 아니라 클렌징 듀오와 수분 루틴 세트 중심

### 금요일: 상세페이지 개선

- 문의/리뷰에서 반복된 질문을 FAQ와 상세 상단에 반영
- 예: 유화는 어떻게 하나요, 아침 세안용인가요, 남자가 써도 되나요

### 주말: 경쟁 변화 확인

- 라운드랩, 세타필, 마녀공장, 한스킨, 이니스프리 등 핵심 경쟁 상품의 가격/리뷰/월 구매 신호를 다시 확인
- 주간 리포트에 경쟁 가격 변화와 대응안을 넣는다.

## 클레임 검사 규칙

제품 태그:

- `기능성_미백`: 화이트닝 톤 케어 크림만 허용
- `기능성_미백_주름`: 영거 댄 올인원만 허용
- `일반화장품`: 나머지 제품, 기능성 표현 금지
- `실증필요`: 수치, 임상, 만족도, 저자극, 개선율, 비교 우위
- `금지위험`: 치료, 완치, 재생, 질병, 절대 효과, 무조건 표현

자동 차단 키워드:

- 치료
- 완치
- 재생
- 회복
- 항염
- 아토피
- 피부염
- 여드름 치료
- 기미 제거
- 잡티 제거
- 멜라닌 억제
- 모공 축소
- 주름 제거
- 부작용 없음
- 100%
- 무조건
- 최고
- 1위
- 피부과 추천

승인 조건:

- 기능성 표현은 기능성 제품 2개에만 허용한다.
- 수치 표현은 시험명, 대상, 기간, 결과, 개인차 문구가 있어야 허용한다.
- 비교 표현은 비교 대상, 기준, 날짜, 출처가 있어야 허용한다.
- 리뷰 표현은 실제 리뷰 원문과 작성 경로가 있어야 허용한다.
- AI 생성 문구는 광고 집행 전 사람이 최종 검수한다.

## 위험 표현과 대체 문구

| 위험 표현 | 대체 문구 |
|---|---|
| 기미 제거, 잡티 제거 | 피부를 화사하게 가꾸는 데 도움 |
| 여드름 치료, 트러블 완치 | 피부 노폐물을 부드럽게 세정 |
| 아토피 완화, 피부염 개선 | 건조한 피부에 편안한 사용감 |
| 피부 재생, 상처 회복 | 피부 컨디션 케어 |
| 모공 축소 | 매끈해 보이는 피부결 케어 |
| 무자극, 부작용 없음 | 개인차가 있을 수 있는 순한 사용감 |
| 1위, 최고, 최강 | 가격, 용량, 리뷰 수 기준 비교 정보 |
| 피부과 추천 | 전성분과 사용 주의사항 공개 |
| 일반 제품에 화이트닝/주름개선 | 맑고 생기 있어 보이는 피부 인상 |

## 30일 실행안

### 1~7일차: 자료실과 검수 체계

- 8개 상품의 상품명, 용량, 가격, 전성분, 이미지, URL, 사용법, 금지 표현을 상품 마스터로 고정
- 클레임 검사 규칙 적용
- 클렌징 듀오와 수분 루틴 세트의 상세 첫 화면 문구 작성
- 리뷰 수집용 설문 항목 확정

### 8~14일차: 콘텐츠 공장 구축

- 주력 4개 제품만 콘텐츠 생성: 토너, 클렌징 오일, 클렌징 젤, 톤 케어 크림
- 제품별 블로그 3개, 릴스 스크립트 5개, 광고 카피 20개 생성
- AI 후보 중 20%만 사람이 골라 발행
- 사용 장면 영상 촬영 목록 확정

### 15~21일차: 광고/상세페이지 실험

- 네이버 쇼핑/검색: 클렌징 듀오, 수분 루틴, 톤 케어 키워드 테스트

## 참고한 공식 자료

- 네이버 광고주센터: 쇼핑검색광고는 광고그룹 또는 상품 단위 입찰이 가능하고, 입찰가는 최소 50원부터 설정 가능.
- 네이버 광고주센터: 사이트검색광고/파워링크 등은 최소 70원부터, 쇼핑검색광고는 50원부터 입찰 가능.
- 쿠팡광고: 매출 최적화 광고와 AI 스마트 광고의 일예산은 최소 1만원부터 설정 가능.
- 쿠팡광고: 상품광고는 입찰 시작가 100원, 하루 1만원부터 시작 가능하다고 안내.
- Meta: Advantage+는 AI 기반으로 타겟, 노출 위치, 예산, 크리에이티브를 자동화할 수 있으나, 성과는 보장되지 않으므로 초기에는 소재 통제가 필요.
- Google Ads: Performance Max의 생성형 AI는 텍스트, 이미지, 로고, 비디오 자산을 제안/생성할 수 있고 광고주가 선택·검토해야 한다.
- 식약처: 화장품 표시·광고는 의약품 오인, 기능성 범위 초과, 사실과 다른 소비자 오인 표현을 피해야 하며 실증이 필요한 경우 자료 제출 요청 대상이 될 수 있다.
