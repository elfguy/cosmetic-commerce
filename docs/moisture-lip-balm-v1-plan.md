## 생성 방침
- GPT Images는 `https://chatgpt.com/images/`에서 시작한다.
- 한 컷씩 생성 → 후보 저장 → 기본 QA → 통과 시 runtime 경로에 승격한다.
- 제품이 꼭 필요한 컷만 제품 이미지를 포함한다. 정보 컷은 제품 반복을 줄인다.
- `11` 법정표/전성분 컷은 텍스트 정확도가 최우선이므로 원본 표를 보존/정리한다.
- 모든 최종 이미지는 780×1360 PNG로 맞춘다.
- 전체 생성 후 manifest, marketingOps, 비교 페이지를 갱신하고 `npm run build`로 검증한다.
