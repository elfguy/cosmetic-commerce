# 02. MVP Scope

## Phase 0 — 준비

- [ ] 브랜드명/제품명/대표 제품 1~3개 확정
- [ ] 제품 사진/패키지/성분표/인증자료 수집
- [ ] 경쟁 브랜드 10개 벤치마크
- [ ] Discord 채널 생성 및 프로젝트 로그 시작

## Phase 1 — 랜딩 + 제품 상세 MVP

- [ ] 홈/브랜드 스토리
- [ ] 대표 제품 상세페이지
- [ ] 피부 고민별 섹션
- [ ] 후기/신뢰 요소 영역
- [ ] 문의/샘플 신청 폼
- [ ] 카카오톡/스마트스토어/전화 연결 CTA

## Phase 2 — 쇼핑몰 기능

- [ ] 제품 목록/상세
- [ ] 장바구니
- [ ] 주문서
- [ ] 결제 연동 후보 검토: Toss Payments, PortOne, 스마트스토어 연결
- [ ] 주문/리드 Supabase 저장

## Phase 3 — 마케팅 자동화

- [ ] SEO 콘텐츠 20개
- [ ] 인스타/블로그 소재 생성 템플릿
- [ ] 광고 랜딩 A/B 테스트
- [ ] 구매/문의 리드 후속 메시지 자동화

## MVP에서 제외

- 복잡한 회원 등급
- 정교한 물류 자동화
- 대규모 재고/ERP 연동
- 다국어/해외 판매
