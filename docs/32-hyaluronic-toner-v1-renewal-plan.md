## 4. 현재 상세의 핵심 문제

### 4.1 아쿠아 로션과 거의 같은 내용

현재 상세는 다음 메시지가 아쿠아 로션과 거의 겹친다.

- 8종 히알루론산
- Fresh Bud No.6
- 피부자극 테스트
- EWG 그린 등급
- 약산성 pH
- 제조 6개월 이내
- 친환경 포장/직접 판매
- 리셀러 주의

이 내용들은 브랜드/제품군 공통 신뢰 요소로는 좋지만, 토너만을 사야 하는 이유를 만들기에는 약하다.

### 4.2 토너만의 사용 맥락이 약함

토너 구매자는 로션 구매자와 다르게 다음 질문을 한다.

- 매일 화장솜에 듬뿍 써도 부담 없는가?
- 세안 후 첫 단계에 산뜻한가?
- 닦토/흡토/스킨팩/레이어링으로 활용 가능한가?
- 500ml 대용량이라 실사용 가치가 있는가?
- 화장 전 피부결 정돈용으로 쓸 수 있는가?

현재 상세는 이 질문에 대한 답보다 성분/인증/공통 신뢰에 많이 치우쳐 있다.

### 4.3 정책/표현 리스크

V1에서 피해야 할 표현:

- `피부 깊은 곳까지`
- `속부터 충전`
- `피부 장벽 강화`
- `진정 효과`
- `민감 피부도 안심`
- `안전한 성분만`
- `피부 개선`, `속건조 해결`, `트러블 완화`, `치료/재생/회복`

권장 대체 표현:

- `피부에 수분감을 더하는 보습 성분`
- `세안 후 첫 단계에 산뜻하게`
- `화장솜에도 넉넉하게`
- `건조하게 느껴지는 날 레이어링`
- `부담 적은 데일리 수분 루틴`
- `피부결 정돈에 도움을 주는 사용감`
- `원료적 특성에 한함`

## 5. 토너 제품만의 특장점 후보

V1에서 전면에 세울 고유 포인트는 아래 순서가 좋다.

1. **500ml 대용량**
   - 경쟁 제품 대비 즉시 이해되는 강점.
   - 10ml당 218원 수준의 가성비와 연결 가능.
   - 화장솜/스킨팩 사용량 부담을 줄여주는 메시지와 잘 맞음.

2. **닦토 · 흡토 · 스킨팩 · 레이어링**
   - 로션/크림과 다른 토너만의 활용성.
   - 상세 04~05번에서 강하게 보여주면 구매 이유가 선명해짐.

3. **세안 후 첫 수분 루틴**
   - 토너 카테고리 본질.
   - `수분 토너`, `저분자 히알루론산`, `피부결 정돈`, `화장 전 산뜻함`과 연결.

4. **8종 히알루론산 + 보습 보조 성분**
   - 현재도 있는 강점이지만 초반 메인보다 중반 근거 컷이 적합.
   - ppm 표기와 8종 구조는 신뢰감을 줄 수 있음.

5. **제조 6개월 이내 / 직접 제조**
   - 아쿠아 로션에서 검증된 신뢰 포인트.
   - 토너에서는 `매일 많이 쓰는 제품이라 신선 출고가 중요하다`로 연결해야 차별화됨.

6. **향료 무첨가 / 약산성 pH 5.0~6.5 / 피부자극 테스트 비자극 판정**
   - 민감·데일리 사용에 대한 불안 제거.
   - 단, `안심`, `무자극`, `장벽 강화`처럼 과장하지 않기.

## 6. V1 상세 이미지 권장 흐름

아쿠아 로션 V4처럼 `대표 6장 + 상세 14~15장` 구조를 목표로 하되, 토너 V1은 **사용량/활용성/첫 수분**을 전면에 둔다.

- 로컬 합성 느낌이 강한 후보는 아쿠아 로션 V4 수준의 GPT Images 2.0 품질 기준에 못 미친다.
- 대표 이미지에 큰 문구/배지가 많으면 쿠팡 썸네일용으로 부적합하다.

## 8. 제작 방식 제안

아쿠아 로션 V4에서 품질을 확보한 방식과 동일하게 진행한다.

1. **현재본 백업/버전 구조 생성**
   - `public/coupang/images/hyaluronic-acid-toner/versions/original/`에 현재 대표/상세 보존
   - `versions/v1/representative/`, `versions/v1/detail/` 생성
   - `manifest.json` 작성

2. **V1 카피보드 확정**
   - 본 문서의 컷별 흐름을 기준으로 `docs/23-hyaluronic-toner-copyboard.md` 업데이트 또는 V1 전용 카피보드 생성
   - 표현 리스크 제거

3. **대표 01부터 제작**
   - 대표 01은 제품 단독/검색 썸네일 중심
   - 제품 라벨 500ml 가독성 확인
   - 작은 신선 배지 여부는 미리 결정

4. **상세는 1컷씩 순차 제작**
   - 아쿠아 로션처럼 GPT Images 2.0 품질 기준으로 한 컷씩 생성/검수
   - 한국어 텍스트 오타/상품명 drift 발생 시 바로 재생성
   - 최종 PNG에는 컷 번호/POINT 번호/STEP 번호가 박히지 않도록 주의

5. **마케팅 사이트 비교 페이지 등록**
   - V1을 현재본과 비교 가능하게 노출
   - 이미지 번호는 페이지 UI 캡션으로만 표시하고 PNG 안에는 넣지 않기

6. **검증 후 쿠팡 반영은 별도 승인**
   - 쿠팡 실제 업데이트 전에는 rollback 백업 필요
   - 대표/상세 이미지 교체 후 OpenAPI 재조회로 CDN URL/상태 검증

## 10. 결론

현재 토너 상세는 나쁘지는 않지만, 아쿠아 로션과 겹치는 공통 성분·인증 설명이 많아서 **토너를 사야 하는 이유가 약하다**.

V1은 다음 메시지로 방향을 명확히 잡는 것이 좋다.

> 500ml라 매일 아끼지 않고,  
> 닦토·흡토·스킨팩까지 쓰기 좋은  
> 제조 6개월 이내 신선 출고 수분 토너.

즉, 토너 V1의 중심은 `8종 히알루론산 고기능`보다 **500ml 대용량 + 사용 루틴 + 신선 출고 신뢰**다.
