# 12. 유어스킨플러스 AI 활용 마케팅 전략

확인일: 2026-05-16

이 문서는 기존 마케팅안을 대체한다. 제품 효능을 증명하지 못한 상태에서 `진정`, `미백`, `PDRN`, `블랙헤드`, `저자극` 같은 표현을 공격적으로 쓰는 방식은 배제한다. AI는 효능을 만들어내는 도구가 아니라, 이미 확인된 사실을 바탕으로 콘텐츠 생산, 고객 응대, 리뷰 분석, 광고 실험, 상세페이지 개선을 빠르게 반복하는 운영 도구로만 쓴다.

## 운영 원칙

### 하지 말 것

- AI에게 효능 카피를 만들게 하지 않는다.
- `개선`, `치료`, `재생`, `모공 축소`, `블랙헤드 제거`, `미백 효과`, `장벽 회복`처럼 실증 없이는 위험한 표현을 쓰지 않는다.
- 생성형 이미지로 사용 전후, 피부 변화, 의학적 효과처럼 보이는 장면을 만들지 않는다.
- 고객 후기처럼 보이는 가짜 문장, 가짜 별점, 가짜 Before/After를 만들지 않는다.
- AI가 만든 답변을 그대로 고객에게 보내지 않는다.

### 할 것

- AI는 상품명, 가격, 용량, 사용법, 전성분, 주의사항처럼 확인 가능한 정보만 기반으로 쓴다.
- AI 출력물은 `광고 가능`, `수정 필요`, `사용 금지`로 사람이 최종 판정한다.
- 콘텐츠는 효능보다 사용 장면, 용량, 가격, 제형, 루틴, 선물/휴대성, 문의 전환에 집중한다.
- 광고 소재는 AI로 여러 버전을 만들되, 실제 제품 사진과 실제 사용 영상이 중심이어야 한다.
- 고객 질문/리뷰/광고 성과를 AI로 요약해서 다음 실험에 반영한다.

## AI 활용 핵심 구조

유어스킨플러스의 AI 마케팅은 `효능 주장`이 아니라 `반복 운영 자동화`다.

```text
상품 자료 정리
→ AI 클레임 검사
→ 상세페이지/스토어 카피 변형
→ 블로그/릴스/광고 소재 생산
→ 고객 질문/리뷰 수집
→ AI 요약 리포트
→ 다음 상세페이지/광고 실험 반영
```

## 3. AI 상세페이지 개선

상세페이지는 AI로 `문장`을 만드는 것보다 `구조`를 빠르게 바꾸는 데 쓴다.

### 공통 상세페이지 구조

1. 실제 제품 사진.
2. 용량/가격/사용 장면.
3. 누구에게 맞는지, 단 효능이 아니라 상황 중심.
4. 제형/패키지/펌프/스틱 같은 물리적 특징.
5. 사용법.
6. 전성분/주의사항.
7. 실제 리뷰 요약, 가짜 후기 금지.
8. 스마트스토어/카카오 문의 CTA.

### 상품별 안전한 상세 방향

| 상품 | 안전한 상세 방향 |
|---|---|
| 히알루론산 토너 | 500ml, 화장솜 사용, 스킨팩, 세안 후 첫 단계 |
| 아쿠아 로션 | 300ml, 얼굴/바디, 무향, 샤워 후 사용 |
| 클렌징오일 | 선크림/메이크업 세정 루틴, 유화 방법, 펌프형 |
| 클렌징젤 | 약산성 컨셉, 아침 세안, 세안 후 당김이 부담스러운 상황 |
| 로즈 에센스 | 로즈 무드, 산뜻한 첫 단계, 선물용 |
| 올인원 로션 | 남성 간편 루틴, 면도 후 사용, 여러 단계 줄이기 |
| 립밤 | 무색, 휴대성, 수시 사용, 남녀공용 |
| 톤 케어 크림 | 기능성 근거 확인 전까지 톤 케어 루틴/피부 표현 중심 |
| PDRN 수딩 크림 | 재생 금지. 수분/보습/수딩 루틴 정도로 제한 |

효능은 주장하지 말고 사용 장면, 용량, 제형, 사용법 중심으로 써줘.

## 4. AI 콘텐츠 생산

블로그, 릴스, 카드뉴스는 효능 설명보다 `실사용 방법` 콘텐츠로 간다.

### 콘텐츠 주제

| 채널 | AI 활용 | 주제 |
|---|---|---|
| 블로그 | 초안/구조/제목 생성 | 500ml 토너 활용법, 클렌징오일 유화 방법, 립밤 휴대 루틴 |
| 릴스/쇼츠 | 스크립트/컷 구성 | 화장솜 토너팩, 펌프 클렌징, 남성 15초 올인원 |
| 카드뉴스 | 문구 변형/레이아웃 문안 | 사용 순서, 제품별 차이, 선물 세트 구성 |
| 카카오채널 | 웰컴 메시지/FAQ | 제품 추천, 사용법 안내, B2B 문의 |
| 스마트스토어 | 상품명/상세 상단 변형 | 검색어 유지 + 고객 언어 요약 |

### 블로그 글 구조

AI에게 다음 구조로만 쓰게 한다.

```text
제목: 제품명 + 사용 장면
1. 이런 상황에서 쓰기 좋음
2. 제품의 확인 가능한 특징
3. 사용 순서
4. 자주 묻는 질문
5. 스마트스토어/카카오 문의 연결
```

예시 제목:

- 500ml 히알루론산 토너, 화장솜에 듬뿍 쓰는 3가지 방법.
- 클렌징오일 유화, 처음 쓰는 사람을 위한 사용 순서.
- 무색 립밤은 언제 쓰면 좋을까: 사무실/가방/자기 전 루틴.
- 남성 올인원 로션, 세안 후 한 단계로 끝내는 아침 루틴.

### 릴스 스크립트 프롬프트

```text
화장품 효능을 주장하지 않는 릴스 스크립트를 만들어줘.
제품의 실제 사용 장면만 보여줘.
문구는 짧고 자막형으로 써줘.
금지: 개선, 제거, 재생, 미백 효과, 모공 축소, 치료.

제품:
핵심 장면:
영상 길이: 12초
출력: 컷 번호 / 화면 / 자막 / 촬영 메모
```

## 5. AI 광고 소재 실험

광고는 AI가 타깃을 맞히게 맡기는 것보다, 사람이 `각도`를 정하고 AI가 변형을 많이 만드는 방식이 맞다.

광고 각도:

| 각도 | 메시지 |
|---|---|
| 용량 | 500ml 토너, 화장솜에 듬뿍 |
| 가격 | 1만원대 데일리 스킨케어 |
| 사용 장면 | 세안 후, 샤워 후, 출근 전, 자기 전 |
| 제형 | 젤, 오일, 로션, 스틱 |
| 편의성 | 펌프형, 무색, 남녀공용, 올인원 |
| 세트 | 수분 루틴, 클렌징 루틴, 선물/답례품 |

소재 매트릭스:

| 제품 | 이미지 | 영상 | 카피 |
|---|---:|---:|---:|
| 토너 | 5개 | 3개 | 10개 |
| 클렌징오일 | 5개 | 5개 | 10개 |
| 클렌징젤 | 4개 | 3개 | 8개 |
| 로션 | 4개 | 3개 | 8개 |
| 립밤 | 4개 | 3개 | 8개 |

Meta/Instagram은 Advantage+ Creative처럼 소재 변형을 자동화하는 기능이 있고, Google Ads도 생성형 이미지 도구를 제공한다. 다만 Google은 생성 이미지가 정확하고 오해 소지가 없는지 광고주가 확인해야 한다고 안내한다. 따라서 AI 생성 이미지는 배경/라이프스타일 보조용으로만 쓰고, 실제 제품 사진과 제품명/가격은 사람이 고정한 소재를 우선한다.

## 6. AI 리뷰/고객 문의 분석

리뷰 원문과 고객 문의가 모이면 AI가 가장 쓸모 있다.

매주 분석할 것:

- 고객이 실제로 쓰는 단어.
- 불만/반품 이유.
- 어떤 사용 장면이 자주 나오는지.
- 상품 설명에서 헷갈리는 부분.
- 세트로 묶을 만한 조합.
- FAQ에 추가할 질문.

리뷰 분석 프롬프트:

```text
다음 리뷰/문의에서 효능 주장을 만들지 말고,
고객 언어와 개선할 상세페이지 정보를 뽑아줘.

출력:
1. 자주 나오는 사용 장면
2. 구매 이유
3. 불만/우려
4. 상세페이지에 추가할 정보
5. 광고 문구로 써도 안전한 표현
6. 광고 문구로 쓰면 위험한 표현
```

## 7. AI 카카오채널/상담

AI 상담은 `추천`보다 `정보 정리` 역할로 제한한다.

상담 봇이 답해도 되는 것:

- 상품 용량.
- 가격/구매 링크.
- 사용 순서.
- 배송/교환 안내.
- B2B 문의 접수.
- 전성분/주의사항 안내.

상담 봇이 답하면 안 되는 것:

- 피부 질환 상담.
- 특정 증상 개선 보장.
- 임산부/질환자/알레르기 관련 단정.
- 기능성 효능 단정.
- 다른 브랜드와 의학적 비교.

카카오채널 기본 버튼:

- 제품 추천받기.
- 스마트스토어에서 보기.
- 사용법 문의.
- 샘플/B2B 문의.

## 30일 실행안

### 1주차: AI 자료실과 금지어 체계

- 상품별 확인 자료를 한 파일로 정리한다.
- 금지어/주의어 리스트를 만든다.
- 기존 상세페이지와 문구를 AI 클레임 검사에 넣어 위험 문구를 제거한다.
- 토너, 로션, 클렌징오일, 클렌징젤 4개만 우선 작업한다.

### 2주차: 콘텐츠 공장 세팅

- AI로 블로그 제목 30개를 만들고 사람이 8개만 고른다.
- 릴스 스크립트 20개를 만들고 6개만 촬영한다.
- 스마트스토어 상세 상단 문구를 상품별 5개씩 생성해 A/B 후보로 둔다.
- 카카오채널 FAQ 초안을 만든다.

### 3주차: 광고 소재 테스트

- 토너와 클렌징오일만 광고 테스트한다.
- 소재는 효능이 아니라 `용량`, `사용 장면`, `제형`, `가격`, `펌프형` 각도로 나눈다.
- Meta/Instagram은 AI 자동 변형 기능을 켜더라도 가격/효능 문구가 바뀌지 않는지 매일 확인한다.
- AI 생성 이미지는 실제 제품 사진을 대체하지 않는다.

### 4주차: 데이터 기반 수정

- AI 주간 리포트로 성과를 요약한다.
- 클릭은 높은데 구매가 낮은 상품은 상세페이지 정보 부족을 점검한다.
- 문의가 반복되는 내용은 상세페이지와 FAQ에 추가한다.
- 다음 달에는 반응이 있던 2개 각도만 키운다.

## 60일 실행안

- 리뷰/문의 데이터를 모아 상세페이지 FAQ를 자동 업데이트하는 루틴을 만든다.
- 블로그는 AI 초안 + 사람 검수 방식으로 주 2개 발행한다.
- 릴스는 AI 스크립트 + 실제 제품 촬영 방식으로 주 3개 만든다.
- 광고 소재는 AI로 20개 만들고, 실제 집행은 사람이 고른 5개만 한다.
- 세트 상품 후보를 AI로 계산하되, 최종 가격은 원가/마진 기준으로 사람이 정한다.

## 비용 구조

AI 활용형은 외주비를 줄이고 반복 실험량을 늘리는 방식이다.

| 항목 | 최소 | 권장 |
|---|---:|---:|
| AI 도구/구독 | 월 30,000~200,000원 | 월 200,000~500,000원 |
| 촬영 소품/조명 | 100,000~300,000원 | 300,000~700,000원 |
| 광고 테스트 | 월 500,000~1,500,000원 | 월 2,000,000~4,000,000원 |
| 샘플/체험단 | 월 300,000~800,000원 | 월 800,000~1,500,000원 |
| 콘텐츠 외주 | 0원 | 필요 시 월 500,000~1,500,000원 |

초기에는 외주를 늘리기보다 AI로 초안을 만들고 직접 촬영/검수하는 편이 낫다. 광고비는 AI 도구비보다 중요하다. AI가 아무리 빠르게 소재를 만들어도 실제 클릭/전환 데이터가 없으면 학습할 수 없다.

## 즉시 할 일

1. 기존 마케팅 문구를 전부 AI 클레임 검사에 넣고 위험 표현을 삭제한다.
2. 상품별 `확인된 사실` 파일을 만든다.
3. 토너/클렌징오일 2개만 AI 소재 매트릭스를 만든다.
4. 실제 제품 사진과 10초 사용 영상을 촬영한다.
5. AI로 블로그/릴스/광고 문구 후보를 만들고 사람이 20%만 고른다.
6. 광고/콘텐츠 결과를 매주 AI 리포트로 요약한다.
