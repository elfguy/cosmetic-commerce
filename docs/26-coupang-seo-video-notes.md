# 26. 쿠팡 SEO 판매 노하우 영상 정리

확인일: 2026-05-21

- 제목: 쿠팡에 내 상품 아무리 검색해도 절대 안나오는 이유
- 채널: 빌리브로 - 정확한 온라인 판매의 기준
- 길이: 23:51

## 수집 상태

- yt-dlp로 메타데이터와 영상 설명은 확인 완료.
- 유튜브 자동자막/수동자막은 제공되지 않음.
- 오디오 다운로드는 YouTube 403으로 차단되어 로컬 전사는 진행하지 못함.
- 따라서 아래 내용은 영상 설명란의 핵심 체크리스트, 제목, 태그, 쿠팡 운영 맥락을 기반으로 유어스킨 실행 문서 형태로 재구성했다.

## 한 줄 요약

쿠팡 검색 노출은 단순 등록이 아니라 상품명, 카테고리, 옵션 구조, 가격 할인, 태그, 외부 유입이 합쳐진 상품 점수 싸움으로 보고 관리해야 한다.

## 핵심 메시지

1. 쿠팡 상품은 RPG 게임의 캐릭터처럼 점수를 쌓아야 노출된다.
2. 상품명은 길게 키워드를 우겨넣기보다 자동완성 검색어 기반 5-6단어로 구성한다.
3. 카테고리는 감으로 고르지 말고 상위 노출 경쟁 상품과 같은 카테고리로 맞춘다.
4. 옵션과 가격 구조가 검색 필터, 할인율, 전환율에 직접 영향을 준다.
5. 상품명에 넣지 못한 연관 키워드는 태그로 보강한다.
6. 쿠팡쇼츠, SNS 등 외부 유입은 알고리즘에 트래픽 신호를 주는 보조 수단으로 쓴다.

## 6단계 체크리스트

### 1. 상품명

영상 설명의 기준은 자동완성 검색어 기반 5-6단어 구성이다.

유어스킨 적용 원칙:

- 브랜드명은 앞에 유지하되, 검색어는 구매자가 실제로 치는 단어를 우선한다.
- 상품명 하나에 모든 성분과 효능을 넣지 않는다.
- 핵심 검색어는 브랜드 + 주성분/기능 + 제품군 + 용량 + 사용 니즈 정도로 압축한다.

예시:

- 현재 방향: 유어스킨플러스 피디알엔 히알루론산 수딩 크림 200ml
- 보강 후보: 유어스킨플러스 PDRN 히알루론산 수딩크림 200ml 속건조 보습
- 토너 후보: 유어스킨플러스 히알루론산 토너 500ml 대용량 수분 스킨

주의:

- 쿠팡 상품명은 검색 노출용이지만 과도하게 길면 썸네일/모바일에서 신뢰감이 떨어진다.
- 의학적 효능, 피부 개선 단정 표현은 상품명에 넣지 않는다.
- PDRN은 컨셉 원료로만 다루고 기능성 효능처럼 쓰지 않는다.

### 2. 카테고리

영상 설명의 기준은 상위 셀러와 동일한 카테고리 선택이다.

유어스킨 적용 원칙:

- 쿠팡에서 핵심 키워드를 검색한 뒤 상위 10개 상품의 카테고리를 확인한다.
- 내 상품 카테고리가 상위권 상품과 다르면 필터 노출에서 빠질 수 있다.
- 특히 스킨케어는 스킨, 로션, 페이셜크림, 클렌징 오일, 폼/젤/파우더/비누처럼 세부 카테고리 일치가 중요하다.

현재 확인된 카테고리:

- 히알루론산 토너: 스킨
- 아쿠아 로션: 로션
- 클렌징 오일: 오일/워터
- 클렌징 젤: 폼/젤/파우더/비누
- 로즈 토닉 에센스: 에센스/세럼/앰플
- 올인원 로션: 올인원
- 립밤: 립케어
- 톤 케어 크림: 페이셜크림
- PDRN 히알루론산 수딩 크림: 페이셜크림

### 3. 옵션 구조

영상 설명의 기준은 단일상품과 옵션상품을 정확히 구분하는 것이다.

유어스킨 적용 원칙:

- 단일 용량 제품은 옵션을 억지로 늘리지 않는다.
- 묶음 구성이 필요한 제품은 옵션명에 수량, 용량, 혜택이 명확해야 한다.
- 검색 필터에서 개당 용량, 수량, 가격대가 꼬이지 않게 관리한다.

점검할 것:

- 립밤은 고시정보 기준 4g이지만 쿠팡 노출 구성 수량은 재확인이 필요하다.
- 수딩크림은 Chrome에서 200ml x 1개로 확인됐다.
- 향후 2개입/세트 옵션을 만들 경우 리뷰와 전환이 분산될 수 있으므로 단일 대표 상품을 먼저 키운다.

### 4. 가격과 할인율

영상 설명의 기준은 정상가 40% 할인과 판매자 자동 가격조정 활용이다.

유어스킨 적용 원칙:

- 현재 유어스킨 쿠팡 상품은 대부분 44-47% 할인 구조라 영상 기준에는 맞는 편이다.
- 할인율은 단순 장식이 아니라 클릭률과 가격 필터 대응에 영향을 준다.
- 자동 가격조정은 경쟁 가격을 따라가되, 마진 하한선을 먼저 정하고 켜야 한다.

현재 가격 메모:

- 히알루론산 토너 500ml: 10,900원, 10ml당 218원
- 수딩크림 200ml: 12,800원, 10ml당 640원
- 톤 케어 크림 200ml: 10,100원, 10ml당 505원

실행 기준:

- 대표 주력 상품은 가격을 자주 흔들기보다 2주 단위로 고정 테스트한다.
- 광고비를 쓰는 상품은 ROAS만 보지 말고 검색 순위 변화와 자연 유입 증가를 같이 본다.
- 정상가 대비 40% 이상 할인이 유지되는지 주 1회 체크한다.

### 5. 태그

영상 설명의 기준은 상품명에 없는 연관 키워드를 모두 태그로 추가하는 것이다.

유어스킨 적용 원칙:

- 상품명에 넣기 애매한 키워드는 태그로 분산한다.
- 성분명, 사용 니즈, 제품군, 용량, 사용 상황을 분리해서 넣는다.
- 허위 효능성 키워드는 넣지 않는다.

수딩크림 태그 후보:

- PDRN
- 히알루론산
- 수딩크림
- 속건조
- 보습크림
- 페이셜크림
- 대용량크림
- 데일리크림
- 민감피부
- 수분크림

히알루론산 토너 태그 후보:

- 히알루론산토너
- 수분토너
- 대용량토너
- 닦토
- 스킨팩
- 저분자히알루론산
- 데일리스킨
- 보습토너

### 6. 외부 유입

영상 설명의 기준은 쿠팡쇼츠와 SNS를 활용해 트래픽을 늘리는 것이다.

유어스킨 적용 원칙:

- 외부 유입은 바로 매출보다 쿠팡 알고리즘에 상품 반응 신호를 주는 용도로 본다.
- 쇼츠/릴스/블로그/카페 글에서 쿠팡 링크로 유입을 만든다.
- 외부 유입 소재는 제품별로 하나의 각도만 잡는다.

제품별 외부 유입 각도:

- 토너: 500ml 대용량, 닦토/스킨팩, 제조 6개월 이내 신선 출고
- 수딩크림: PDRN/히알루론산 컨셉, 속건조 보습, 200ml 대용량
- 톤 케어 크림: 미백 기능성, 자연스러운 톤 케어, 200ml 대용량
- 클렌징젤: 약산성, 아침 세안, 세안 후 당김 완화 니즈
- 클렌징오일: 1차 세안, 블랙헤드/메이크업 세정 니즈. 단 제거 단정은 피함

## 유어스킨 9개 상품 우선순위

1. 히알루론산 토너
   - 최근 판매 발생, 500ml 대용량 단가 경쟁력, 상세 리뉴얼 진행 중.
   - 상품명/태그/대표이미지 최우선 테스트 대상.

2. 피디알엔 히알루론산 수딩 크림
   - 새로 매칭된 9번째 상품.
   - PDRN 키워드 수요가 있으나 표현 리스크가 있어 전성분 확인 후 카피 확정 필요.

3. 화이트닝 톤 케어 크림
   - 미백 기능성 고시가 있어 검색 포지션이 명확함.
   - 톤 케어/미백 키워드와 200ml 대용량을 같이 가져갈 수 있음.

4. 클렌징젤/클렌징오일
   - 루틴 묶음과 외부 콘텐츠로 확장하기 좋음.
   - 단, 경쟁이 강하므로 상세 이미지와 사용감 증거가 필요함.

## 바로 실행할 일

- 쿠팡 Wing에서 9개 상품의 상품명, 카테고리, 태그, 옵션, 정상가/판매가를 캡처한다.
- 상위 경쟁 상품 5개씩 카테고리와 상품명을 비교한다.
- 히알루론산 토너, 수딩크림, 톤 케어 크림부터 상품명 2안씩 만든다.
- 상품명에 넣지 못한 키워드를 태그로 분리한다.
- 광고/외부유입 테스트는 한 번에 여러 상품을 건드리지 말고 토너부터 시작한다.

## 유어스킨 적용 체크리스트

- [ ] 상품명 5-6단어 원칙 점검
- [ ] 상위 셀러 카테고리와 일치 여부 확인
- [ ] 옵션 구조가 단일/세트 기준으로 명확한지 확인
- [ ] 정상가 대비 40% 이상 할인 구조 유지 여부 확인
- [ ] 상품명 외 키워드 태그 보강
- [ ] 쿠팡쇼츠/SNS 외부 유입 소재 1개 제작
- [ ] 검색 순위와 자연 주문 변화를 주 단위로 기록

## 주의할 표현

- PDRN 재생, 피부 재생, 피부 회복처럼 의학적/기능성 오해가 있는 표현은 피한다.
- 천연화장품은 근거가 없으면 쓰지 않는다.
- 블랙헤드 제거, 여드름 개선, 피부 장벽 회복 등은 시험/고시 근거 없이 쓰지 않는다.
- 안전한 대체 표현은 보습, 수분감, 편안한 마무리, 데일리 케어, 자연유래 보습 성분 함유 수준으로 둔다.

## 결론

이 영상의 핵심은 쿠팡 검색 노출을 운이나 광고비 문제가 아니라 상품 등록 품질과 반응 신호의 누적 문제로 보라는 것이다. 유어스킨은 이미 가격 할인율과 대용량 포지션은 괜찮으므로, 다음 개선 포인트는 상품명/태그/카테고리 정합성, 대표 이미지, 외부 유입 신호를 주력 상품부터 순서대로 테스트하는 것이다.
