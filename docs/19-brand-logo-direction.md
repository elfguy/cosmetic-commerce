# 유어스킨플러스 브랜드 로고 방향 정리

확인일: 2026-05-17

## 목적

유어스킨플러스 제품을 단순 저가 화장품이 아니라 자연 성분 기반의 프리미엄 클린 뷰티 브랜드로 보이게 만드는 로고 방향을 정리한다. 현재 단계의 산출물은 최종 CI 원본이 아니라, 자사몰 상세 페이지와 패키지 리뉴얼을 위한 브랜드 방향성 보드다.

## 핵심 방향

- 브랜드명: `YOURSKIN PLUS`
- 인상: 자연 성분, 신선한 추출, 순한 사용감, 건강한 피부 장벽, 신뢰감 있는 한국형 프리미엄 코스메틱
- 디자인 톤: 절제된 서울 뷰티 감성, 스칸디나비아식 여백, 현대적인 산세리프 타이포그래피
- 심볼: 이슬방울 외곽, 한 장의 잎, 얇은 잎맥, 작은 플러스 포인트로 압축
- 배제할 것: 장식적인 잎사귀, 스파 로고처럼 보이는 곡선, 과한 금색, 저가형 뷰티 로고, 만화적 표현

## 추천 콘셉트

`Calm Leaf Drop` 방향을 1순위로 잡는다.

이유:
- 이슬방울은 수분감과 순한 사용감을 직관적으로 전달한다.
- 잎맥은 자연 유래 성분과 추출 원료 이미지를 만든다.
- 기존 드롭, 잎맥, 순환선 조합보다 작은 크기에서 더 잘 읽힌다.
- 작은 골드 플러스로 `PLUS`의 의미를 남기되 기능성/의료 느낌을 줄인다.

## 로고 구조

| 요소 | 방향 |
| --- | --- |
| 워드마크 | `YOURSKIN PLUS`를 넓은 자간의 얇은 산세리프로 사용 |
| 심볼 | 드롭 아웃라인 안에 한 장의 잎과 잎맥을 배치 |
| 플러스 | 의료/기능성처럼 강하게 쓰지 않고 작은 골드 포인트로 절제 |
| 기본 조합 | 심볼 상단, 워드마크 하단의 세로형 락업 |
| 보조 조합 | 심볼 단독, 흑백 버전, 패키지용 소형 락업 |

- 심볼 단독 벡터 초안: `public/brand/yourskin-plus-symbol.svg`
- 생성 보드 이미지: `public/brand/logo-concepts/` 로고 후보 시안. 02번을 현재 기준 시안으로 사용

## 사용 가이드

- 상세 페이지 첫 화면에서는 컬러 로고보다 심볼 단독을 작게 쓰고, 제품명과 효능 근거를 더 크게 둔다.
- 자사몰 헤더에서는 워드마크 중심, 패키지 전면에서는 심볼 중심으로 쓰는 것이 좋다.
- 골드는 5% 이하로 제한하고, 딥그린과 아이보리를 기본 조합으로 둔다.
- 기능성/의료 느낌이 과해지지 않게 하려면 플러스를 크게 키우지 말고, 신뢰 배지나 성분 섹션에서 보조적으로 사용한다.

## 다음 작업

1. 선택한 심볼을 실제 벡터 원본으로 다시 정리한다.
2. 24px, 48px, 96px 작은 크기에서 식별성을 테스트한다.
3. 쿠팡 상세 첫 화면, 네이버 대표 이미지, 자사몰 헤더에서 각각 적용 샘플을 만든다.
4. 패키지에는 로고보다 제품명과 용량 정보가 먼저 읽히도록 계층을 조정한다.
