# 14. 유어스킨플러스 자사몰 쇼핑몰 목업 디자인 정리

확인일: 2026-05-17

목적: `유어스킨플러스 / Your Skin Plus`를 천연 소재, 신선한 원료 유통, 깨끗한 제조 과정, 프리미엄 자연주의 스킨케어 브랜드로 보이게 하기 위한 자사몰 쇼핑몰 목업 방향을 정리한다.

## 현재 목업 4종

프로젝트 루트(`/`)는 판매/마케팅 운영 대시보드로 사용한다. `/coupang-mock` 라우트는 쿠팡 저장 HTML 기반 상품 상세 분석 화면으로 유지한다.

| 라우트 | 목업 방향 | 핵심 역할 |
|---|---|---|
| `/shop-concept` | 내추럴 프리미엄 | 브랜드 대표안. 아이보리, 세이지, 제품 중심 히어로로 고급 천연 화장품 톤을 만든다. |
| `/shop-clinical` | Fresh Ingredient Chain | 산지, 선별, 저온 보관, 제조, 배송 흐름을 보여주는 유통 신뢰형 안. |
| `/shop-luxury` | 미니멀 클린 뷰티 | 여백, 성분 투명성, 정돈된 제품 정보를 중심으로 한 클린 뷰티 안. |
| `/shop-editorial` | 자연 라이프스타일 | 따뜻한 자연주의 루틴과 감성적인 제품 사용 장면을 강조하는 안. |

## 최종 추천 방향

실제 자사몰 쇼핑몰로 발전시키기 좋은 방향은 `내추럴 프리미엄 + 미니멀 클린 뷰티` 조합이다.

- 첫 화면은 `/shop-concept`처럼 천연 소재와 신선함을 브랜드 메시지로 제시한다.
- 정보 구조는 `/shop-luxury`처럼 제품, 성분, 원료 출처, Fresh Chain을 간결하게 정리한다.
- 상세페이지 이미지를 그대로 크게 쓰는 방식은 피하고, 제품 누끼와 원료/라이프스타일 이미지를 분리해서 사용한다.
- 구매 CTA는 “지금 제품 보기”, “신선한 원료 확인하기”, “Fresh Chain 살펴보기” 정도로 단순화한다.

## 타이포그래피 기준

현재 공통 한글 폰트는 `IBM Plex Sans KR` 중심 스택으로 정리했다.

```css
--font-body: 'IBM Plex Sans KR', 'Pretendard', 'Apple SD Gothic Neo', sans-serif;
--font-display: 'IBM Plex Sans KR', 'Pretendard', 'Apple SD Gothic Neo', sans-serif;
--font-latin: 'Manrope', 'IBM Plex Sans KR', sans-serif;
--font-serif: 'Cormorant Garamond', serif;
```

운영 기준:

- H1: 500 weight, 54~56px 수준. 너무 굵은 700~900 weight는 피한다.
- H2: 550 weight, 34px 수준. 섹션 제목도 과하게 굵지 않게 유지한다.
- 본문: 400~500 weight, 1.7~1.8 line-height.
- 버튼: 650 weight 이하. 쇼핑몰 배너처럼 과하게 굵은 버튼 텍스트는 피한다.
- 한글 자간은 0을 기본값으로 유지한다.
- 영문 로고/내비게이션은 `Manrope`로 정리해 한글 본문과 구분한다.

## 이미지 사용 기준

자사몰 쇼핑몰 첫 화면에 피해야 할 이미지:

- 쿠팡 상세페이지 안의 큰 제목/체크리스트가 그대로 보이는 이미지
- 흰 사각 배경이 장식 배경 위에 어색하게 얹히는 제품컷
- 제품 위에 가격 카드가 겹쳐 제품을 가리는 배치
- 의학적 효과나 Before/After처럼 보이는 이미지

자사몰 쇼핑몰 첫 화면에 권장하는 이미지:

- 제품 누끼 이미지 또는 깨끗한 제품 단독 컷
- 원료 이미지는 배경/보조 요소로 낮게 사용
- 제품 정보 카드는 제품 위에 겹치지 않고 별도 영역에 배치
- 자연광, 아이보리 배경, 세이지/올리브 포인트를 사용

## 목업별 개선 기록

### `/shop-concept`

- 기존 상세 이미지 기반 히어로를 제품 단독 스테이지로 변경했다.
- 제품 위에 겹치던 정보 카드를 제거하고 아래 정보 카드로 분리했다.
- 장식 잎 형태가 어색하게 겹치던 배경 요소를 제거했다.

### `/shop-clinical`

- 원료 유통 단계를 `산지 → 선별 → 저온 보관 → 제조 → 배송`으로 명확히 표현했다.
- 카드 높이와 제목 굵기를 낮춰 공공기관/농산물 유통 서비스처럼 보이는 느낌을 줄였다.

### `/shop-luxury`

- 라우트명은 유지하지만 콘셉트는 미니멀 클린 뷰티로 정의한다.
- 상세 배지가 붙은 제품컷 대신 더 깨끗한 제품 중심 이미지를 사용했다.
- 블랙 버튼은 유지하되 제목 크기와 굵기를 낮춰 투박함을 줄였다.

### `/shop-editorial`

- 체크리스트형 상세 이미지를 첫 화면에서 제거했다.
- 제품 중심 비주얼과 따뜻한 크림/피치/올리브 팔레트로 라이프스타일 톤을 유지했다.
