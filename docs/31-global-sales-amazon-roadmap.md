# 해외판매 준비 전략 — Amazon US 중심

확인일: 2026-06-05  
연결 문서: `30-amazon-kbeauty-market-research.md`

## 목적

유어스킨플러스/YOURSKIN PLUS 제품을 해외, 특히 Amazon US에 실험 판매하기 위한 시장조사 방법, 에이전트 운영 방식, 준비 체크리스트, 0~120일 실행 타임라인을 정리한다.

## 핵심 판단

아마존은 브랜드 감성보다 검색·전환 언어가 먼저다. 초기에는 “프리미엄 자연주의”를 전면에 세우기보다 `Korean functional skincare`로 번역해야 한다.

- 톤/미백: `Dark Spot`, `Brightening`, `Niacinamide`, `TXA`, `Even Tone`
- 수분/진정: `Barrier Repair`, `Centella`, `Ceramide`, `Sensitive Skin`, `Glass Skin`
- 탄력/안티에이징: `PDRN`, `Collagen`, `Peptide`, `Retinal`, `Firming`, `Plumping`

## 시장조사 방법

1. 카테고리 지도 만들기
   - Amazon Best Sellers > Beauty & Personal Care > Skin Care
   - `korean skincare`, `dark spot serum korean`, `barrier cream korean`, `pdrn collagen cream`, `toner pads korean` 검색
2. 상위 30개 제품 표준 필드 수집
   - 브랜드, 제품명, ASIN, 가격, 리뷰 수, 평점, 월 구매 신호, 핵심 성분, 대표 문제, 이미지 메시지, 쿠폰 여부
3. 키워드 클러스터링
   - 수요형: `dark spot`, `pore`, `sensitive skin`, `glass skin`, `wrinkle`
   - 성분형: `niacinamide`, `TXA`, `centella`, `PDRN`, `collagen`, `retinal`
   - 제형형: `serum`, `cream`, `toner pad`, `hydrogel mask`, `balm stick`
4. 리뷰 마이닝
   - 별점 1~3점: 끈적임, 자극, 향, 용기, 배송 파손, 효과 체감 부족
   - 별점 5점: 빠른 흡수, 촉촉함, 민감피부 적합, 메이크업 전 사용감
5. 우리 제품 후보화
   - 보유 성분과 키워드의 일치율
   - 아마존에서 이미 수요가 검증된 문제 해결 각도
   - 미국 라벨/표현/성분 검증 난이도
   - FBA 물류 적합성

## 1차 진입 후보

1. Niacinamide/TXA Dark Spot Serum 계열
   - 이유: 검색 의도가 명확하고 `dark spot`, `even tone`, `brightening` 전환 언어가 강하다.
   - 확인: 실제 TXA/나이아신아마이드 포함 여부, 기능성 표현 가능 범위.
2. Centella/Ceramide Barrier Cream 계열
   - 이유: 40대+ 자연주의와 민감피부 장벽 케어가 잘 맞는다.
   - 확인: 센텔라/세라마이드/히알루론산 등 성분 증거, 향/알코올 여부.
3. Collagen/PDRN Firming Cream or Balm 계열
   - 이유: PDRN/콜라겐이 현재 K-Beauty 트렌드로 강하다.
   - 확인: PDRN 실제 포함 여부, `anti-aging` 표현의 안전한 대체 문구.
4. Toner Pad 신규 SKU
   - 이유: medicube 등 토너패드 수요가 매우 강하다.
   - 확인: 생산/ODM, 안정성, 패드 재질, 성분 농도.
5. Overnight Hydrogel Mask 신규 SKU
   - 이유: BIODANCE류 오버나이트 마스크 수요가 강하다.
   - 확인: ODM 가능성, 단가, 파손/건조 리스크.

## 0~120일 타임라인

### 0~14일: 리서치와 SKU 후보 선정

- 보유 11개 제품 전성분/용량/단가/재고/제조사 자료 정리
- Amazon 상위 30~50개 경쟁 ASIN 수집
- 키워드 클러스터별 시장성 점수화
- 후보 SKU 3개 선정
- 제품별 Amazon 제목/bullet/A+ 초안 작성

### 15~30일: 규정·라벨·원가 검증

- 미국 화장품 라벨 필수 항목 체크
- INCI 영문명, 순중량, 제조/유통 책임자, 원산지, 경고문 검토
- MoCRA/FDA 관련 등록·책임자·시설 요건 확인 필요
- FBA 수수료/배송비/관세/반품비 포함 마진 계산
- Amazon Seller 계정·Brand Registry 가능성 확인

### 31~45일: 콘텐츠 제작

- 메인 이미지: 흰 배경, 제품 크게, 패키지 영문 가독성
- 서브 이미지 6~7장: 성분, 문제 해결, 사용법, 피부 타입, 루틴, 안전 표현
- A+ Content: 브랜드 스토리보다 문제 해결과 성분 신뢰 중심
- 상세 문구에서 치료/의약품 오해 표현 제거

### 46~60일: 리스팅 준비와 소량 물류

- Seller Central 리스팅 초안 생성
- UPC/GTIN 면제 또는 바코드 정책 확인
- FBA vs FBM 선택: 초반은 소량 FBM/3PL 테스트 후 FBA 전환도 가능
- 샘플/패키지 내구성/영문 라벨 부착 테스트
- 사진·문구·가격·쿠폰 세팅

### 61~90일: 런칭 실험

- 1~3개 SKU만 런칭
- 쿠폰/초기 할인/PPC 소액 집행
- 자동 캠페인 + 정확 키워드 캠페인 병행
- 매주 CTR, CVR, ACOS, 리뷰, 반품 사유 확인
- 전환 낮으면 이미지 1~3번과 제목을 먼저 수정

### 91~120일: 확장 또는 중단 판단

- 기준 충족 SKU만 재고 추가
- 광고비 대비 매출, 리뷰 확보 속도, 반품률로 판단
- 가능하면 Brand Store/A+ 고도화
- 우승 SKU 기반 세트/번들/대용량/여행용 확장

## 결정 게이트

- Gate 1: 후보 SKU가 아마존 검색 키워드와 70% 이상 맞는가?
- Gate 2: 미국 라벨/성분/표현 리스크가 해결 가능한가?
- Gate 3: FBA/FBM 후에도 목표 마진이 남는가?
- Gate 4: 콘텐츠 제작 없이도 제품 자체 차별점이 설명 가능한가?
- Gate 5: 90일 테스트 후 재주문/리뷰/전환 신호가 있는가?
