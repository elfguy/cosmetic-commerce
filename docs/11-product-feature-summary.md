# 11. 유어스킨플러스 상품별 특장점 정리

확인일: 2026-05-16

현재 레포의 `data/yourskin-products.json`, 네이버 검색 메모, 쿠팡 저장 HTML, Cafe24 원본 HTML을 기준으로 상품별 판매 포인트를 정리했다. 상세 이미지 안에만 들어 있는 문구는 OCR 전이라 일부 빠질 수 있으므로, 아래 내용은 현재 텍스트로 확인 가능한 정보와 안전한 마케팅 카피 제안을 분리해 활용한다.

## 공통 브랜드 메시지

유어스킨플러스는 `매일 부담 없이 쓰는 실용 스킨케어`를 중심 메시지로 잡는 것이 좋다. 제품군 전반에서 반복되는 강점은 대용량, 합리적 가격, 수분/보습, 산뜻한 사용감, 데일리 루틴 적합성이다.

추천 문장:

- 매일 쓰는 스킨케어, 더 넉넉하고 편안하게.
- 피부 루틴에 부담 없이 더하는 실용 보습 케어.
- 복잡한 설명보다 매일 손이 가는 사용감에 집중한 데일리 스킨케어.
- 수분, 보습, 클렌징까지 일상 루틴에 맞춘 유어스킨플러스.

표현 주의:

- 피해야 할 표현: 치료, 완치, 항염, 여드름 개선, 모공 축소, 피부 재생, 피부 깊숙이 침투.
- 완화할 표현: `블랙헤드 제거` → `블랙헤드가 신경 쓰이는 부위의 세정 관리`.
- 완화할 표현: `미백된다` → `맑고 균일해 보이는 피부 표현`, `브라이트닝 루틴`, `톤 케어`.
- 완화할 표현: `피부 회복` → `편안한 보습 마무리`, `건조한 부위에 덧바르는 수딩 케어`.

## 저분자 히알루론산 토너 500ml

확인 정보:

- 네이버 노출명: 유어스킨플러스 저분자히알루론산토너 스킨 원액 앰플 500ml.
- 쿠팡 옵션: 500ml x 1개.
- 쿠팡 가격: 10,900원, 정가 표기 20,000원, 10ml당 218원.
- 카테고리: 스킨/여성기초화장품.
- 노출 속성: 남녀공용, 얼굴용, 피부고민 진정/보습, 모든 피부.

상세페이지 후킹:

- 세안 후 첫 수분, 500ml로 넉넉하게 채우는 히알루론산 토너.
- 닦토, 스킨팩, 레이어링까지 부담 없이 쓰는 대용량 수분 베이스.

특장점:

- 500ml 대용량이라 화장솜 사용, 스킨팩, 여러 번 덧바르는 루틴에 부담이 적다.
- 히알루론산 수분 컨셉을 앞세워 건조함이 자주 느껴지는 고객에게 설명하기 쉽다.
- `스킨`, `토너`, `원액`, `앰플` 검색어가 상품명에 포함되어 검색 대응력이 좋다.

추천 사용 장면:

- 세안 후 손바닥이나 화장솜으로 피부결 정돈.
- 건조한 부위에 2~3회 레이어링.
- 화장솜에 충분히 적셔 짧은 수분팩으로 활용.

- 노출 속성: 보습, 얼굴용, 무향, 피부고민 진정/보습.

상세페이지 후킹:

- 가볍게 펴 바르고 산뜻하게 마무리하는 데일리 보습 로션.
- 끈적한 보습이 부담스러운 날, 얼굴과 바디에 넉넉하게 쓰는 300ml 로션.

특장점:

- 300ml 용량으로 얼굴뿐 아니라 목, 팔, 다리 등 건조한 부위까지 사용 장면을 확장하기 좋다.
- 무향과 산뜻한 마무리를 중심으로 민감한 향을 싫어하는 고객에게 소구 가능하다.
- 히알루론산 보습 컨셉을 토너/수딩 크림과 묶어 수분 루틴으로 구성하기 좋다.

추천 사용 장면:

- 토너 다음 단계에서 얼굴 전체에 얇게 펴 바르기.
- 샤워 후 건조한 바디 부위에 추가 사용.
- 아침에는 얇게, 저녁에는 한 번 더 레이어링.

상세페이지 후킹:

- 메이크업과 선크림, 피지를 부드럽게 녹이는 첫 세안 클렌징 오일.

추천 사용 장면:

- 마른 손과 얼굴에 2~3회 펌핑.
- 코 주변과 턱 라인을 부드럽게 롤링.
- 물을 묻혀 하얗게 유화한 뒤 미온수로 충분히 헹굼.
