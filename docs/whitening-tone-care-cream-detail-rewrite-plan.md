## 핵심 제작 원칙

1. **상품 이미지 비율 보존**
   - 상품 용기 이미지를 사용할 때 가로/세로 비율을 절대 변경하지 않는다.
   - 제품을 늘리거나 압축하지 않는다.
   - 크기 조정은 반드시 비율 고정 스케일만 사용한다.
   - 제품 라벨, 캡 높이, 용기 폭, 원형 용기 곡률이 달라지면 실패로 본다.
   - GPT Images가 제품을 새로 그리면서 용기 비율/라벨/용량을 바꾸면 최종 사용하지 않는다.

2. **문구 표현 기준**
   - 사용 가능: `피부의 미백에 도움`, `미백 기능성화장품`, `나이아신아마이드 함유`, `칙칙해 보이는 피부 인상 관리`, `데일리 톤 케어`, `브라이트닝 컨셉 원료`.
   - 피할 표현: `즉시 하얘짐`, `강력한 화이트닝 효과`, `기미/잡티 제거`, `피부톤 개선 보장`, `멜라닌 제거`.
   - 글루타티온/토코페롤은 기능성 성분이 아니라 원료 컨셉으로만 표현한다.

3. **전체 디자인 톤**
   - 기존 아쿠아 로션/히알루론산 토너 리뉴얼 상세처럼 모바일 가독성 높은 카드형 구성을 따른다.
   - 컬러: 화이트, 아이보리, 연한 민트, 아주 연한 샴페인 골드.
   - 분위기: 깨끗한 크림, 진주빛, 부드러운 광택, 순한 기능성 화장품.
   - 과한 경고판, 오래된 증빙 이미지 그대로 삽입, 작은 글씨 과다 사용은 피한다.

4. **이미지 생성 방식**
   - 한 장씩 생성하고 QA 후 다음 컷으로 진행한다.
   - GPT Images 사용 시 기존 승인 컷과 실제 제품 이미지를 참조로 업로드한다.
   - 상품이 들어가는 컷은 실제 제품 형태/비율/라벨을 기준으로 확인한다.
   - 텍스트가 많은 컷은 GPT Images 안에서 텍스트까지 생성하되, 오탈자/깨진 한글이 있으면 재생성한다.
