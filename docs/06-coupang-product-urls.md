## 제외한 후보

- 유어스킨플러스 비타민 플러스 화이트닝 크림
  - 공식몰/외부 제품 후보로는 보이나, 현재 쿠팡 검색 화면에서는 확인되지 않음.
  - 2026-05-17 Chrome/Coupang 확인 기준 8개 상품 목록에는 포함하지 않는 것으로 정리.

## 접근/차단 메모

Codex 실행 환경에서 쿠팡 검색/상세 URL 접근을 시도했을 때 다음 현상이 있었다.

- `curl` 접근: Akamai `Access Denied` 응답.
- Codex 인앱 브라우저 자동화 접근: `net::ERR_BLOCKED_BY_CLIENT`.
- 사용자 브라우저에서는 동일 상품 URL 접근 가능.

따라서 현재 문제는 사용자 IP 블록보다는 Codex 인앱 브라우저/자동화 환경의 클라이언트 측 차단 가능성이 높다.

가능성이 높은 원인:

- 쿠팡 상세 URL 또는 광고/트래킹 파라미터가 인앱 브라우저 차단 필터에 걸림.
- 자동화 컨텍스트와 사용자가 직접 보는 브라우저 컨텍스트의 세션/확장/요청 경로 차이.
- 쿠팡의 자동화 탐지 가능성도 있으나, 에러 형태상 서버 403보다 클라이언트 차단 쪽이 더 유력.

## 후속 확인 방법

현재 Chrome에서 확인된 유어스킨플러스 쿠팡 상품은 8개다. 이후 누락 의심 상품이 생기면 아래 중 하나로 확인한다.

1. 쿠팡 Wing 상품관리 화면에서 `productId`, `itemId`, `vendorItemId` 확인.
2. 사용자가 쿠팡 검색 결과에서 추가 상품 상세 URL을 직접 열어 공유.
3. 쿠팡 검색 결과에서 `유어스킨플러스` 8개 외에 새로 노출되는 상품명 확인.

최종 URL은 추적 파라미터를 제거한 기본 형태로 관리한다.

```text
https://www.coupang.com/vp/products/{productId}?itemId={itemId}&vendorItemId={vendorItemId}
```
