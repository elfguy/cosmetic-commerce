# 25. 쿠팡 히알루론산 토너 경쟁 승리 전략

작성일: 2026-05-20

대상 상품: 유어스킨플러스 히알루론산 토너 500ml

목적: 상세 이미지를 예쁘게 만드는 문제가 아니라, 쿠팡에서 이미 강한 브랜드와 경쟁할 때 어떤 포지션과 운영 방식으로 이길 수 있는지 정리한다.

## 1. 결론

유어스킨플러스 토너는 아누아, 토리든, 라운드랩 같은 브랜드와 **성분 브랜딩/감성/리뷰 수**로 정면승부하면 불리하다.

이길 수 있는 방향은 다르다.

> 오래된 재고 걱정 없이, 매일 아끼지 않고 쓰는 500ml 대용량 수분 토너

핵심 포지션:

- 직접 제조
- 제조 6개월 이내 제품 보장
- 500ml 대용량
- 10,900원 합리 가격
- 닦토, 흡토, 스킨팩까지 매일 쓰는 실사용 토너

즉, “예쁜 브랜드 토너”가 아니라 **실속형 데일리 수분 토너**로 이겨야 한다.

## 2. 정면승부를 피해야 할 영역

다음 영역은 대형 브랜드가 이미 강하다.

| 경쟁 축 | 왜 불리한가 | 대응 |
|---|---|---|
| 브랜드 인지도 | 아누아/토리든/라운드랩은 이미 검색 수요와 팬층이 있음 | 브랜드 감성보다 실사용 가치로 포지셔닝 |
| 리뷰 수 | 경쟁 상품은 리뷰/구매량이 많음 | 초기에는 리뷰 수보다 가격/용량/제조 신뢰로 설득 |
| 성분 브랜딩 | 어성초 77, 저분자 히알루론산, 독도 등 기억 장치가 강함 | 8종 히알루론산은 보조 근거로만 사용 |
| 상세페이지 완성도 | 대형 브랜드는 촬영/디자인 품질이 높음 | 상세 퀄리티 정면승부보다 상품명/가격/세트/광고 효율로 우회 |
| 프리미엄 이미지 | 패키지/브랜드 무드에서 밀릴 수 있음 | 프리미엄 대신 제조 신뢰와 대용량 실용성 강조 |

## 3. 우리가 이길 수 있는 영역

### 3.1 제조 신뢰

대부분의 쿠팡 화장품은 제조일자를 전면에 세우지 않는다. 유어스킨플러스는 직접 제조와 제조 6개월 이내 보장을 차별점으로 쓸 수 있다.

핵심 문구:

- 제조 6개월 이내 제품 보장
- 직접 제조한 데일리 수분 토너
- 오래된 재고 걱정을 줄인 최근 제조 제품
- 제조일자와 사용기한 확인 가능

주의:

- 제조 신뢰는 대표이미지보다 상세 초반/상품 설명/FAQ에 반복한다.
- 실제 운영상 6개월 이내 출고가 계속 지켜져야 한다.

### 3.2 500ml 대용량

500ml는 가격 경쟁의 핵심이다. 단, “싸다”가 아니라 “아낌없이 쓴다”로 번역해야 한다.

핵심 사용 장면:

- 화장솜에 충분히 적셔 닦토
- 손바닥에 덜어 흡토
- 건조한 날 스킨팩
- 아침저녁 데일리 사용
- 얼굴, 목, 바디 건조 부위까지 활용

핵심 문구:

- 아끼지 않고 쓰는 500ml 수분 토너
- 닦토, 흡토, 스킨팩까지 넉넉하게
- 매일 쓰는 토너라면 용량이 중요합니다

### 3.3 가격/단가

현재 쿠팡 기준 토너는 500ml 10,900원, 10ml당 218원이다. 이건 실용 구매자에게 강한 무기다.

전략:

- 대표 상품은 10,900원 단품으로 진입 장벽을 낮춘다.
- 토너 2개 세트로 재구매/가족 사용 수요를 만든다.
- 토너+로션 세트로 객단가를 올린다.

## 4. 상품명 전략

쿠팡에서 상품명은 검색 노출과 클릭 판단에 직접 영향을 준다. 브랜드 감성보다 검색어와 구매 이유가 먼저다.

### 추천 상품명

1순위:

> 유어스킨플러스 히알루론산 토너 500ml 대용량 수분 토너 닦토 스킨팩

2순위:

> 유어스킨플러스 히알루론산 토너 500ml 대용량 스킨 수분토너

3순위:

> 유어스킨플러스 저분자 히알루론산 토너 500ml 닦토 스킨팩

### 포함할 키워드

- 히알루론산 토너
- 수분 토너
- 대용량 토너
- 토너 500ml
- 닦토
- 스킨팩
- 스킨

### 조심할 키워드

- 원액: 실제 제형과 맞지 않으면 과장 느낌
- 앰플: 토너 상품과 혼동 가능
- 저자극: 시험 근거 없으면 대표 표현 위험
- 천연화장품: 인증/근거 없으면 사용 금지

## 5. 대표이미지 전략

Leo 지적처럼 쿠팡의 잘 팔리는 상품 대표이미지는 글씨가 거의 없다. 따라서 대표이미지에서 설득하려 하지 않는다.

### 1번 대표이미지

역할: 검색 결과에서 깨끗하고 신뢰감 있게 보이기

구성:

- 흰 배경
- 제품 정면 단독
- 텍스트 없음
- 제품 라벨과 500ml 표기가 보이게
- 자연스러운 그림자

금지:

- 제조 6개월 배지
- 500ml 큰 그래픽
- 성분 리스트
- 사용법 아이콘
- 광고 배너형 디자인

### 2번 이미지부터 설득

2번 이미지부터 아래 메시지를 넣는다.

- 매일 쓰는 토너라면, 넉넉하고 신선하게
- 제조 6개월 이내 제품 보장
- 닦토, 흡토, 스킨팩까지 아낌없이
- 직접 제조한 500ml 수분 토너

## 6. 상세페이지 전략

상세페이지의 목표는 “예뻐 보이는 것”이 아니라 쿠팡 고객의 구매 불안을 순서대로 제거하는 것이다.

추천 순서:

1. 대표이미지: 제품 단독
2. 첫 설득: 매일 쓰는 500ml 수분 토너
3. 문제 공감: 토너는 생각보다 빨리 줄어듦
4. 사용 장면: 닦토/흡토/스킨팩/레이어링
5. 제조 신뢰: 직접 제조, 제조 6개월 이내 보장
6. 성분 근거: 8종 히알루론산, 자연유래 보습 성분
7. 사용감: 산뜻한 수분감, 끈적임 부담 완화
8. 추천 대상
9. 사용법
10. 고시정보/전성분

우선 교체해야 할 것:

- 기존 고시정보의 120ml 표기 제거
- 제조 3개월 이내 문구를 6개월 보장 기준으로 통일
- 대표이미지는 텍스트 없는 제품 중심으로 교체
- 상세 초반은 성분 설명보다 사용 장면/용량/제조 신뢰로 재배열

## 7. 가격/세트 전략

단품만으로 쿠팡에서 크게 이기기는 어렵다. 단품은 유입 상품, 세트는 매출 상품으로 나눈다.

### 단품

상품:

> 히알루론산 토너 500ml

역할:

- 검색 유입
- 가격 비교 진입
- 리뷰 확보
- 광고 테스트

가격:

- 현재 10,900원 유지 권장
- 가격을 올리기보다 세트로 객단가 상승

### 토너 2개 세트

상품명:

> 유어스킨플러스 히알루론산 토너 500ml 2개 대용량 수분토너

권장가:

- 19,900~20,900원

역할:

- 재구매/가족 사용
- 500ml 대용량의 실용성 강화
- 광고 전환 단가 개선

### 토너 + 아쿠아 로션 세트

상품명:

> 유어스킨플러스 히알루론산 토너 500ml + 아쿠아 로션 300ml 수분 루틴 세트

권장가:

- 19,900~21,900원

역할:

- 토너 단품보다 객단가 상승
- 수분 루틴으로 구매 이유 강화
- 상세페이지 만들기 쉬움

### 3종 수분 루틴 세트

구성:

- 토너 500ml
- 아쿠아 로션 300ml
- 클렌징 젤 300ml 또는 클렌징 오일 300ml

권장가:

- 29,900~32,900원

역할:

- 월 매출 목표용 객단가 상품
- 쿠팡보다 스마트스토어/직접 유입에도 적합

## 9. 리뷰 전략

쿠팡에서 리뷰 수는 브랜드 인지도를 보완하는 핵심 신뢰 장치다. 리뷰는 그냥 기다리면 늦다.

### 리뷰에서 얻고 싶은 키워드

- 대용량
- 촉촉함
- 산뜻함
- 화장솜에 쓰기 좋음
- 스킨팩으로 쓰기 좋음
- 제조일자 확인
- 가성비
- 매일 쓰기 좋음

### 리뷰 유도 방식

- 구매 후 안내 카드에 사용법을 짧게 안내
- “화장솜/스킨팩/아침저녁 사용 후 느낀 점을 남겨주세요”처럼 자연스럽게 유도
- 제조일자 확인 가능 문구를 동봉 카드에 넣어 신뢰 포인트를 상기
- 리뷰 대가성/조건부 표현은 쿠팡 정책 위반 가능성이 있으므로 주의

### 초기 리뷰 확보 우선순위

1. 기존 구매자 리뷰 키워드 분석
2. 지인/오프라인 샘플 사용 후 쿠팡 구매 전환 유도
3. 스마트스토어 리뷰와 쿠팡 리뷰를 분리 운영
4. 리뷰가 늘어난 키워드를 상세 상단에 반영

## 10. 쿠폰/프로모션 전략

할인은 무작정 크게 하지 않는다. 유어스킨플러스는 저가 브랜드처럼 보이면 안 되고, 실속형 데일리 브랜드처럼 보여야 한다.

추천:

- 단품은 가격 유지
- 토너 2개 세트에서 묶음 할인
- 토너+로션 세트에서 체감 할인
- 첫 구매 쿠폰은 스마트스토어 중심
- 쿠팡은 광고 효율을 보며 쿠폰 테스트

쿠팡 테스트 예시:

| 상품 | 프로모션 |
|---|---|
| 토너 단품 | 10,900원 유지 |
| 토너 2개 세트 | 19,900원 테스트 |
| 토너+로션 | 20,900원 테스트 |
| 3종 세트 | 29,900원 테스트 |

## 11. 2주 실행 플랜

### Day 1~2: 상품 기본 정리

- 대표이미지 글씨 없는 제품 중심으로 교체
- 상품명 키워드 보강
- 120ml 고시정보 오류 수정
- 제조 6개월 보장 문구 기준 통일
- 상세 2번 이미지에 핵심 설득 문구 반영

완료 기준:

- 대표이미지 1번 교체
- 상품명 변경
- 고시정보 오류 제거

### Day 3~5: 세트 구성

- 토너 2개 세트 등록
- 토너+로션 세트 등록
- 세트 대표이미지 제작
- 세트 상세 초반만 간단히 제작

완료 기준:

- 단품 1개 + 세트 2개 운영

### Day 6~7: 광고 시작

- 토너 단품 캠페인
- 대용량 토너 캠페인
- 수분 루틴 세트 캠페인
- 일예산은 무리하지 말고 반응 확인용으로 시작

완료 기준:

- 키워드별 클릭/전환 데이터 확보 시작

### Day 8~10: 데이터 판단

- 클릭률 낮은 키워드 제거
- 전환 키워드 상품명/상세에 반영
- 세트 가격 조정
- 리뷰 키워드 확인

완료 기준:

- 살릴 키워드 3~5개 선정

### Day 11~14: 확장 또는 정리

- 전환 나는 캠페인 예산 증액
- 안 팔리는 세트는 가격/구성 수정
- 상세페이지 초반 3컷만 추가 개선
- 리뷰/문의에서 반복되는 불안을 FAQ에 반영

완료 기준:

- 토너 단품/세트 중 어느 쪽으로 밀지 결정

## 12. 승리 조건

쿠팡에서 유어스킨플러스 토너가 이기는 조건은 다음이다.

1. 대표이미지가 쿠팡 문법에 맞게 깔끔하다.
2. 상품명에 핵심 검색어가 들어간다.
3. 500ml 대용량 이점이 바로 이해된다.
4. 제조 6개월 이내 보장이 신뢰 포인트로 작동한다.
5. 단품이 아니라 세트로 객단가를 만든다.
6. 광고는 키워드 반응을 보고 2주 단위로 조정한다.
7. 리뷰에서 대용량/산뜻함/제조일자/가성비 키워드가 쌓인다.
