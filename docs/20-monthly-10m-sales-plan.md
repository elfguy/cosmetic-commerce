# 20. 유어스킨플러스 월 매출 1,000만원 달성 30일 실행 전략

작성일: 2026-05-19
목표: 쿠팡 + 네이버 스마트스토어를 중심으로 1개월 매출 1,000만원을 최대한 빠르게 달성한다.

## 1. 결론

1개월 매출 1,000만원은 단품 1만원대 화장품만 광고로 밀어서 달성하기 어렵다. 현재 유어스킨플러스 상품은 대부분 9,600~12,800원 구간이고 리뷰 수는 23~34개 수준이다. 경쟁 상품 대비 가격 경쟁력은 있지만, 리뷰 신뢰와 브랜드 인지가 약하다.

첫 달 전략은 다음 4가지다.

1. 단품 판매가 아니라 세트/묶음 판매로 객단가 29,900~49,900원을 만든다.
2. 쿠팡과 스마트스토어에서 대표 3개 상품군만 집중한다.
3. 광고는 ROAS를 바로 맞추려 하기보다 리뷰/전환 데이터/랭킹 신호를 만드는 투자로 본다.
4. 순수 검색광고만으로 1천만원을 만들지 말고, 리뷰 체험단 + 지인/오프라인 샘플 + 스마트스토어 쿠폰 + 쿠팡 광고를 동시에 돌린다.

추천 목표 구조:

| 구분 | 목표 매출 | 핵심 역할 |
|---|---:|---|
| 쿠팡 | 4,500,000원 | 검색 수요, 빠른 구매 전환, 광고 테스트 |
| 스마트스토어 | 4,000,000원 | 쿠폰/리뷰/검색SEO/재구매 기반 |
| 직접 유입/B2B/지인 공동구매 | 1,500,000원 | 초기 매출 속도 보강, 리뷰/사진 확보 |
| 합계 | 10,000,000원 | 30일 1차 목표 |

## 2. 매출 목표를 주문 수로 쪼개기

현재 단품 평균 판매가는 대략 10,000~12,000원이다. 이 상태로 월 1,000만원을 만들려면 800~1,000건 가까운 주문이 필요하다. 초기 브랜드에는 너무 높다.

| 평균 객단가 | 월 1,000만원 필요 주문 수 | 일평균 주문 수 |
|---:|---:|---:|
| 10,900원 | 918건 | 31건/일 |
| 19,900원 | 503건 | 17건/일 |
| 29,900원 | 335건 | 12건/일 |
| 39,900원 | 251건 | 9건/일 |
| 49,900원 | 201건 | 7건/일 |

실행 기준은 객단가 29,900원 이상이어야 한다. 첫 달은 단품 리뷰/검색 노출을 살리되, 실제 매출 목표는 세트에서 만든다.

## 5. 채널별 전략

## 5.1 쿠팡 전략

쿠팡은 검색 의도가 강하고 구매가 빠르다. 다만 리뷰/랭킹/가격 경쟁이 치열하다. 첫 달 쿠팡 목표는 단순 수익보다 대표 상품 랭킹 신호와 구매 데이터 확보다.

쿠팡에서 우선할 것:

1. 대표 단품 4개 상세 첫 화면 교체: 토너, 로션, 클렌징 오일, 클렌징 젤.
2. 세트 상품 등록 또는 옵션 구성: 토너+로션, 클렌징 오일+젤, 토너+로션+클렌징 젤.
3. 쿠팡 광고는 수동 성과형 광고로 핵심 키워드 테스트 후 반응 있는 상품만 매출 최적화 광고로 확장.
4. 상세 첫 화면 메시지는 500ml 대용량, 매일 쓰는 수분 루틴, 순한 데일리 클렌징, 제조사 직접 운영/합리 가격 중심.

### 쿠팡 광고 운영안

쿠팡 공식 광고 FAQ에 따르면 상품광고는 구매 의도를 가진 고객에게 노출되고 클릭이 발생했을 때 과금되는 CPC 구조다. 매출 최적화 광고는 목표 광고수익률과 예산을 기반으로 키워드/노출지면/입찰가를 자동 선택하며, 최적화에 약 7~14일이 걸릴 수 있다. 쿠팡 매출 최적화 안내는 일예산 3만원 이상을 권장한다.

첫 14일 권장 세팅:

| 캠페인 | 상품 | 일예산 | 목적 |
|---|---|---:|---|
| 쿠팡 수분 루틴 테스트 | 토너, 로션, 토너+로션 세트 | 20,000~30,000원 | 수분/대용량 키워드 반응 |
| 쿠팡 클렌징 테스트 | 클렌징 오일, 클렌징 젤, 클렌징 세트 | 20,000~30,000원 | 클렌징 키워드 반응 |
| 쿠팡 3종 세트 테스트 | 3종 루틴 세트 | 10,000~20,000원 | 객단가 상품 전환 테스트 |

첫 달 쿠팡 광고비 권장: 100만~180만원. 공격형은 200만~300만원.

쿠팡 KPI:

| 지표 | 7일 판단 기준 |
|---|---|
| 클릭률 | 낮으면 대표 이미지/상품명 교체 |
| 장바구니/구매 전환 | 낮으면 상세 첫 화면/가격/쿠폰 조정 |
| 광고 ROAS | 초반은 손익보다 키워드 반응 판단 |
| 리뷰 증가 | 구매 후 리뷰 이벤트/동봉물 점검 |
| 세트 판매 비중 | 30% 미만이면 객단가 전략 실패 |

## 5.2 네이버 스마트스토어 전략

스마트스토어는 쿠팡보다 브랜드 설명, 쿠폰, 리뷰, 블로그/검색 유입 연결이 좋다. 첫 달에는 네이버에서 브랜드 신뢰와 객단가를 만든다.

스마트스토어에서 우선할 것:

1. 스토어 홈 정리: 대표 이미지/로고 교체, 첫 화면에 세트 3개 배치, 대용량 수분/순한 클렌징/가족 보습 루틴 카테고리 구성.
2. 상품명 구조 정리: 브랜드명 + 핵심 키워드 + 용량 + 사용 장면.
3. 쿠폰 구조: 스토어찜 쿠폰, 소식알림 쿠폰, 세트 전용 쿠폰, 리뷰 작성 포인트/재구매 쿠폰.
4. 네이버 콘텐츠 연결: 블로그 10개, Q&A형 콘텐츠 20개, 제품 사용법 카드뉴스/숏폼.

상품명 예시:

- 유어스킨플러스 히알루론산 토너 500ml 대용량 수분 스킨팩
- 유어스킨플러스 약산성 클렌징젤 300ml 순한 젤클렌저
- 유어스킨플러스 클렌징오일 300ml 대용량 1차 세안

### 네이버 쇼핑검색광고 운영안

|---|---|---:|---|

첫 달 네이버 광고비 권장: 100만~180만원. 공격형은 200만~300만원.

## 7. 30일 실행 로드맵

### Week 0: 시작 전 2~3일 준비

목표: 광고 전에 팔릴 구조를 만든다.

- 제품별 원가/마진/재고 확인
- 무료배송 기준 결정
- 세트 판매가 확정
- 쿠팡/스마트스토어 대표 이미지 교체
- 상세페이지 첫 화면 4개 교체
- 리뷰 이벤트 문구/동봉 카드 준비
- 광고용 키워드 목록 작성
- 효능/기능성 표현 검수

완료 기준:

- 세트 3개 등록
- 대표 이미지 4개 교체
- 상세 첫 화면 4개 교체
- 광고 캠페인 5개 준비

### Week 1: 노출 시작과 반응 확인

목표: 클릭되는 상품/키워드 찾기.

- 쿠팡 광고 일 5만~8만원 시작
- 네이버 광고 일 5만~7만원 시작
- 스마트스토어 쿠폰 세팅
- 블로그 콘텐츠 3개 발행
- 리뷰 요청 메시지/동봉물 적용
- 지인/오프라인 샘플 20세트 배포

### Week 2: 승자 상품 집중

목표: 반응 있는 2~3개 상품만 증액.

- 광고비 하위 30% 상품 중단
- 상위 상품 일예산 1.5~2배 증액
- 세트 가격/쿠폰 A/B 테스트
- 상세페이지 후기/사용법 섹션 추가
- 블로그 콘텐츠 4개 추가
- 체험단 20~30명 진행

### Week 3: 객단가 상승

목표: 매출 속도를 만든다.

- 스마트스토어 3종 세트 쿠폰 강화
- 쿠팡 세트 상품 광고 증액
- 리뷰 50개 목표로 구매자 후속 메시지 점검
- 인스타/릴스 사용 장면 소재 5개 업로드
- 지역 꽃집/피부샵/미용실 샘플 영업 10곳

Week 3 판단:

- 객단가 25,000원 미만이면 1천만원 달성 가능성이 낮다.
- 세트 비중이 30% 미만이면 상품 구성/가격/상세 첫 화면을 다시 바꾼다.
- 광고 ROAS만 보지 말고 리뷰 증가와 세트 전환을 같이 본다.

### Week 4: 매출 마감 캠페인

목표: 월말 매출을 밀어 올린다.

- 월말 루틴 세트 한정 쿠폰
- 스마트스토어 알림받기 쿠폰 발송
- 쿠팡 광고 승자 상품만 유지
- 직접/B2B 납품 제안 마감
- 재구매 쿠폰 발행
- 다음 달 주력 상품 2개 결정

## 8. 상세페이지/대표 이미지 개선 방향

### 첫 화면 공식

첫 화면은 예쁘기보다 바로 이해돼야 한다.

구성:

1. 제품명
2. 용량/가격 장점
3. 사용 장면
4. 루틴 제안
5. 안전한 성분 포인트
6. 리뷰/평점 신뢰 요소

예시 문구:

- 매일 부담 없이 쓰는 500ml 대용량 수분 토너
- 세안 후 첫 단계, 촉촉한 수분 루틴
- 클렌징 오일 + 젤로 끝내는 데일리 세안 루틴
- 가족이 함께 쓰기 좋은 대용량 보습 라인
- 기능성 표현은 고시 상품에 한해 고시 범위로 사용

피해야 할 문구:

- 트러블 완치
- 블랙헤드 제거
- 모공 축소
- 피부장벽 회복
- 미백 효과 보장
- 주름 제거
- 피부과 시술급

### 대표 이미지 방향

쿠팡/네이버 대표 이미지는 검색결과에서 작게 보인다.

필수:

- 제품 실물 크게
- 용량/세트 구성이 한눈에 보이게
- 배경은 밝고 깨끗하게
- 텍스트는 1~2개만
- 브랜드명보다 구매 이유가 먼저 보이게

대표 이미지 문구 예:

- 500ml 대용량 수분 토너
- 토너+로션 수분 루틴
- 클렌징 오일+젤 2종 세트
- 데일리 3종 루틴 세트

## 9. 리뷰 확보 전략

리뷰 수가 가장 큰 병목이다. 첫 달에는 리뷰 증가를 매출 목표와 같은 레벨로 봐야 한다.

목표:

| 항목 | 목표 |
|---|---:|
| 대표 4개 상품 리뷰 증가 | 각 +20개 |
| 세트 상품 리뷰 | 각 +10개 |
| 사진/영상 리뷰 | 최소 30개 |
| 스마트스토어 찜/알림 | 찜 300+, 알림 100+ |

방법:

- 구매 후 리뷰 작성 쿠폰
- 동봉 카드: 사용 순서 + 리뷰 안내 + 재구매 쿠폰
- 체험단은 제품만 뿌리지 말고 사진/사용감/구매전환 가능 리뷰를 조건으로 한다.
- 리뷰 요청은 효능 유도 표현 없이 사용감 중심으로 받는다.
- 사진 리뷰에는 욕실/화장대/세안대 사용 장면을 요청한다.

## 10. 광고 예산

월 1천만원을 첫 달에 빠르게 노리려면 최소 300만~500만원의 테스트 예산이 현실적이다.

| 항목 | 예산 |

## 14. 리스크

### 광고비 손실

1만원대 단품은 광고 손익이 빡세다. 세트 전환 없이 광고비만 쓰면 ROAS가 맞지 않는다. 광고 시작 전 세트 상품과 쿠폰 구조를 먼저 만든다.

### 효능 표현 리스크

화장품은 표현 규제가 강하다. 특히 기능성 고시가 없는 상품에 미백/주름/트러블/장벽 회복/치료성 표현을 쓰면 위험하다.

### 리뷰 신뢰 부족

리뷰 수 20~30개대는 경쟁 상품 대비 약하다. 첫 달에는 리뷰 증가를 매출과 같이 관리해야 한다.

### 브랜드 프리미엄과 가격 포지션 충돌

현재 가격은 합리적/가성비인데, 새 로고와 패키지는 프리미엄 방향이다. 너무 고급스럽게만 가면 가격과 메시지가 어긋날 수 있다. 합리적인 대용량 프리미엄 데일리 케어 정도가 안전하다.

## 15. 최종 추천

1차 목표 1,000만원을 빠르게 노리려면 다음 순서가 가장 현실적이다.

1. 토너+로션 세트, 클렌징 2종 세트, 3종 루틴 세트를 먼저 만든다.
2. 쿠팡은 검색 전환용, 스마트스토어는 브랜드/쿠폰/리뷰용으로 나눈다.
3. 첫 14일은 전 상품 광고 금지. 대표 4개 상품과 세트 3개만 테스트한다.
4. 월 1천만원은 객단가 3만원 이상에서 가능하다. 단품 중심이면 주문 수가 너무 많다.
5. 광고비 300만~500만원은 준비해야 한다. 최소 예산으로는 매출 1천만원보다 승자 상품 검증이 현실적이다.
6. 첫 달 KPI는 매출뿐 아니라 리뷰 +100개, 세트 비중 30% 이상, 객단가 29,900원 이상이다.
